How loss is read

  

    
Illustration, not a reading. A fitting's pressure drop is its loss coefficient C times the velocity pressure of the flow through it: Δp = C · ρ v² / 2. Doubling the flow quadruples the drop; changing C changes it in proportion. No fitting in the Snowdon sample exposes a writable C, so the experiment does not touch it: on a copy it writes each duct's computed velocity and size into that duct's Comments and reads them back, so you can see the numbers a drop would be built from.
