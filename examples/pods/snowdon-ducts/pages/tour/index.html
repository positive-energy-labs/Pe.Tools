How loss is read

  

    
Illustration, not a reading. A fitting's pressure drop is its loss coefficient C times the velocity pressure of the flow through it: Δp = C · ρ v² / 2. Doubling the flow quadruples the drop; changing C changes it in proportion. The experiment nudges C on one fitting and reads the value back; whether the model recomputes system totals is something you check in Revit.
