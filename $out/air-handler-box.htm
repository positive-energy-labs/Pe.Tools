Ductwork Box (Air Handler Box, Triangle Box) (Manual D Ductsize Drawing Objects)

The Ductwork Box objects help you improve the drawing, but they do not affect any of the program's calculations.  There are two types of Ductwork Box objects: the Air Handler Box and the the Triangle Box.  The Triangle Box object can be set to a Triangle or Quad Box.

To add an Air Handler Box object to the drawing, drag it from the catalog and drop it onto a Supply Main Trunk or Return Main Trunk object.  Only one Air Handler Box object is permitted for each main trunk duct.

To add a Triangle Box or Quad Box object to the drawing, drag it from the catalog and drop it onto a duct that does not yet have a triangle or quad box.  It will center itself over the junction fitting at the downstream end of the duct.

Note that the Ductwork Box object consists of two objects:  the Ductwork Box polygon, and the text object that shows the name of the box, named, "Ductwork Box Name."

Properties

Box Name:  This property lets you set the text to whatever you want.  You may set this property for either the Ductwork Box or its associated Ductwork Box Name object.

Ductwork Box Type:  This read-only property either says, "Air Handler Box" or "Triangle Box."

Triangle Box Type:  Specifies whether the triangle box type is Triangle or Quad.  This property is only available for Triangle Box and Quad Box objects.

Popup Menu Commands

Center Over Blower Motor Symbol:  Moves the Ductwork Box so that it is centered over the center of the blower motor symbol of the duct to which it belongs.  This popup menu item is only available if the Ductwork Box is set to be an Air Handler Box.

Center Box Over Junction Fitting:  Moves the Ductwork Box so that it is centered over the junction fitting at the downstream end of the duct.  This popup menu item is only available if the Ductwork Box is set to be a Triangle Box.

Center Name Over Box:  Centers the separate Ductwork Box Name object over the Ductwork Box object.

Set to Triangle Box, Set to Quad Box:  Sets the box to either of the two styles of triangle box.  This item is only available if the Ductwork Box Type is Triangle Box.

Reset Box Size and Shape:  Sets the box size and shape to be the same as the default.

Edit Box Polygon:  Puts the object and the drawing in an editing mode where you may edit the points that make up the polygon for the box.  When in editing mode, click and drag anywhere on the polygon to create a new point.  To move an existing point, click on the point and drag it to a new location.  Hold down the Ctrl key while dragging a point to make the point snap to the grid.  To delete a point, click on the point and press the backspace key.  When you are finished editing the polygon, right click in a blank part of the drawing and click, "Close Open Object" from the popup menu.

Delete Box:  Deletes the Ductwork Box object from the drawing.  Also deletes the corresponding Ductwork Box Name object.
