Check Errors (Room Data Window)

Check Errors (Before Leaving Room):  Select Yes to make it so Rhvac automatically checks for input errors whenever you try to go to another room, close the Room Data window, or exit the program.  If there are any input errors, such as a zero width for a glass, etc., the Evaluation of Room window will pop up and display the list of errors, and will not let you leave the room or even close the program until you fix the errors.  If you select No, any input errors will still be checked before the program calculates, and will be displayed in the Evaluation of Project window.  

Note:  Unlike the rest of the inputs on the Room Data window, this input is not saved on a per room basis, but it remains as Yes or No until you change it.  You can navigate from one room to the next a little bit faster if you enter No in this input.
