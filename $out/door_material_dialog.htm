Navigation:  Program Windows > Project Windows > Room Data > Inputs > Door >

Door Material Dialog

Click the button beside the Door Material input on the Room Data or Default Room Data window to open this dialog.

Favorites Tab:  Lists the doors you have added to your Favorites collection.  Double click an item in the list to select that door.

Recent Tab:  Lists your most recently selected door materials.  Double click an item in the list to select that door.

Custom Tab:  Lists the custom doors that you have created by clicking the Create Custom button.  Double click an item in the list to select that door.

Door Item List:  The bottom list on this dialog, which lists all of the standard doors plus any custom doors you have created.  Double click on a door in this list to select it.  Click any of the column headers to sort the list by that column.  Click the same column again to reverse the sort order.

Create Custom Button:  Opens the Custom Door dialog, which lets you enter a custom door material to be added to your list of Custom doors.  Custom doors are always the bottom item in any of the sub category lists.

Organize Button:  Displays a menu that lets you select to organize your Favorites, Recent or Custom doors.

Add To Favorites Button:  Adds the currently selected door to your Favorites list.

OK Button:  Copies the currently selected door back to the Room Data or other window and closes this dialog.

Cancel Button:  Closes this dialog without copying a door to the Room Data or other window.
