Adding HVAC Equipment to Project Bill of Materials (Project Bill of Materials Window)

Bill of Materials Topics

One way to add the heating and cooling equipment that you have selected for the current project to the project bill of materials is to click "Part | Add HVAC Equipment from Current Project" in the Project Bill of Materials window's toolbar.  That will open the "Add HVAC Equipment to Bill of Materials" dialog, shown below.

System No.:  Specifies which system from which to copy the equipment, if you have entered rooms into more than one system.

Unit Type:  Specifies whether you want to copy the heating unit, outdoor cooling unit, or indoor cooling unit.

Model Type:  Shows the type of equipment that you selected.  This input is read-only.

Part No.:  Shows the part number for the unit you selected.  This input is read-only.

Search for Part in Database:  Searches the bill of materials database for the indicated part number.  If found, this dialog will close and the part will be shown in the Bill of Materials Parts Database window (which is open in the background).  Then you can add the part to the project bill of materials as you would any other part.

Add Part to Database:  Closes this dialog and opens the Add Part dialog, which will already have the Part Number input filled in with the model number of the unit.

Add Part to Project Bill of Materials:  Adds the indicated part directly to the project bill of materials without adding it to the bill of materials database.

Close:  Closes this dialog without making any further changes.

You can also add the current project's HVAC equipment to the project bill of materials from the System Data window.  To do that, click the Add to Bill of Materials button, as shown below.  Then from the popup menu select whether you want to add the heating unit, the outdoor cooling unit, or the indoor cooling unit.  The program will then search your bill of materials database for any parts that match the appropriate model number.  If found, the part will be copied from your database to the project bill of materials.  If not found in the database, the part will be added directly to your project bill of materials with zeroes for the pricing data.  Then, as with any other manually added part, you can edit the pricing data or any other data for that item.
