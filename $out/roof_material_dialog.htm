Roof Material Dialog

Navigation:  Program Windows > Project Windows > Room Data > Inputs > Roof >

Roof Material Dialog

Click the button beside the Roof Material input on the Room Data or Default Room Data window to open this dialog.

Also see the Roof Type Selection topic.

Favorites Tab:  Lists the roofs you have added to your Favorites collection.  Double click an item in the list to select that roof.

Recent Tab:  Lists your most recently selected roof materials.  Double click an item in the list to select that roof.

Custom Tab:  Lists the custom roofs that you have created by clicking the Create Custom button.  Double click an item in the list to select that roof.

Main Category Option Buttons:  Determines the type of roof categories listed in the category list (the one in the middle of this window).  Different roof categories have different heating and cooling load characteristics.  See the Roof Type Selection topic for descriptions of each type.

Sub Category List:  The middle list on this dialog.  Displays the sub categories available under the current main category tab.  Click on an item in the list and the bottom list will show the various roof items available in that sub category.

Roof Item List:  The bottom list on this dialog.  Displays the roofs available in the current sub category.  Double click on a roof in this list to select it.  Click any of the column headers to sort the list by that column.  Click the same column again to reverse the sort order.

Mat & Color Button:  Opens the Extended Roof Options dialog, which lets you set the material and color for the current roof.  This option is only used to help you document the project and does not affect the calculations.

Create Custom Button:  Opens the Custom Roof dialog, which lets you enter a custom roof material to be added to your list of Custom roofs.  Custom roofs are always the bottom item in any of the sub category lists.

Organize Button:  Displays a menu that lets you select to organize your Favorites, Recent or Custom roofs.

Add To Favorites Button:  Adds the currently selected roof to your Favorites list, including roof material and color options if you have selected them.

OK Button:  Copies the currently selected roof back to the Room Data or other window and closes this dialog.

Cancel Button:  Closes this dialog without copying a roof to the Room Data or other window.
