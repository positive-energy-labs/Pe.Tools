Supply Trunk

You will need to drag and drop one of these onto the drawing for each system you are using in your rooms in Rhvac.  The System Number property of this object must correspond to the system number of the rooms you have created on the drawing that this duct feeds.  

This object is where the default data for all the trunks and runouts is saved.  You should set default data immediately after creating this object by right clicking on it, then clicking "General Duct Settings | Duct Defaults for this System" from the popup menu.  

The blower motor symbol indicates the upstream end of the trunk, where the air handler will be.  The Return Main Trunk also has a blower motor symbol, which you should normally position in the same place as the symbol on this object.

High Velocity Supply Main Trunk

This object is the same as the Supply Main Trunk object, except for a couple of differences.  One is that defaults from a different global default scenario file are assigned to it when it is created.  The scenario will normally include characteristics such as a fixed diameter of 2 inches for runouts and a fixed diameter of 7 inches for trunks.  The other difference is that different default fill colors are assigned to it and any ducts you connect to it.

Return Trunk

You will normally need to have one of these for each Supply Main Trunk on the drawing, and you will need to set the System Number property to the same value as that of the supply object.  

The blower motor symbol doesn’t necessarily imply that there is a separate return fan in addition to the supply fan; it is only used to help you distinguish this object from other trunks.  Position the blower motor symbol directly on top of (or underneath) the same symbol of the Supply Main Trunk object.

Pay careful attention to a couple of this object’s properties that are in the Fan category on the Object Properties window.  One is called, "Add Return Loss to Supply," which determines whether or not the return duct system losses and total effective length are added to the cumulative loss values of the supply side.  The other is called, "Subtract Ventilation for Return Airflow" and determines whether or not any ventilation air is subtracted from the supply airflow value in determining the total amount of airflow to assign to the return runouts.
