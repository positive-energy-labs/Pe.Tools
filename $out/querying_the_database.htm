Querying the Database (Bill of Materials Parts Database Window)

Bill of Materials Topics

The left side of this window is where you enter the query that is used to generate the list of parts shown on the right side of this window.

Shown below are the controls on the other query tabs on this dialog.  Each checkbox list has Mark and Clear buttons at the top, which check and uncheck each checkbox in the list.

Current Query:  This box shows the actual database query text that was used to generate the current list.  The text in this box gets updated immediately after you click the Search button.

Load:  Opens the "Load a Saved Query" dialog, shown below, where you can load a query that you saved earlier.  

Delete Selected:  Deletes the currently selected query from the list.

Load Selected Query:  Closes this dialog and loads the currently selected query into the Bill of Materials  Parts Database window.

Close:  Closes this dialog without loading a query.

Save:  Saves the current query for later use.

Clear:  Clears the current query.  All checkboxes are checked and all text inputs are emptied.

Search:  Performs the search of the database and fills up the list on the right with parts that meet your query criteria.
