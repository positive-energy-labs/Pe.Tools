Find HVAC Equipment (Tools Menu)

Icon: .  Keyboard Shortcut:  ALT, T, F

Opens the Find HVAC Equipment window, where you can select air conditioners, heat pumps, and other HVAC equipment for the current project.  Data can be automatically copied to the System Data window's Equipment tab by simply double-clicking an item in the list.

Note:  To select other HVAC equipment manufacturer files to download from the Elite Software website, click the menu "Help | Check for HVAC Equipment Update."

Filename:  Opens the Open Manufacturer Database dialog where you can select an MDB file to use for this window.

Type:  From the dropdown list, select the type of equipment you want to search for.

Model:  If you would like to search for full or partial model number, enter it here and click 'Find Now'.

Cool cap, Heat cap, Min and Max:  If you would like to restrict your search to only those units which are within a certain capacity range, enter the minimum and/or maximum values (in MBH) and click 'Find Now'.

Cool eff, Heat eff, Min and Max:  If you would like to restrict your search to only those units which are within a certain efficiency range, enter the minimum and/or maximum values and click 'Find Now'.

Find Now:  Searches through the selected database for all the models that meet the desired criteria.  The number of models found will be displayed in the first panel of this window's statusbar.

All Zeros:  Changes all the Min and Max inputs to zero so you can generate a fresh search.

Select:  Copies data from the selected item to the System Data window.  This button is only available if the System Data window is also open.  Double clicking on the list has the same effect.

Multipliers:  Opens the Find HVAC Equipment Multipliers dialog, which lets you set the percentages by which to multiply the heating or cooling load in order to set the capacity ranges on the Find HVAC Equipment window when opened from the System Data window.
