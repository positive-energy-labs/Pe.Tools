Options - Background Tab (Tools Menu)

Icon: .  Keyboard Shortcut:  ALT, T, O

Opens the Rhvac Options dialog, where you can set custom preferences for Rhvac.

Click another tab on the picture below to go to help on that tab.

Default:  Sets the background color to the default for an application workspace, usually dark gray.

Custom color:  Sets the background color to one that you specify.

Wallpaper:  Draws a picture on the background of the main window.

Display:  Specifies how you want the background picture to be drawn.  The choices are Center, Tile, Stretch and Fit.

Filename:  Specifies the filename on your computer of the picture file to be used as background wallpaper.  Several picture formats are supported.  Click the dropdown arrow button to the right of this input to select a picture file.

OK button:  Applies any changes you have made and closes this dialog.

Cancel button:  Closes this dialog without making any changes.

Apply button:  Applies any changes you have made to this dialog and leaves the dialog open.
