Select Reports (File Menu)

Icon: .  Keyboard Shortcut:  CTRL+P

Opens the Select Reports dialog, allowing you to select reports to be printed or previewed, and to set various options regarding the appearance of the reports.

Click another tab on the picture below to go to help on that tab.

f

Button Descriptions

Up Arrow button:  Collapses all the report categories.

Down Arrow button:  Expands all the report categories.

Mark All button:  Checks all the report selection boxes.

Clear All button:  Unchecks all the report selection boxes.

Save as Default button:  Saves all of your report selection checkboxes so you can load them in another project later.

Load Default button:  Loads a previously saved set of report selection checkboxes.  This button is only enabled once you have saved your report selections using the "Save as Default" button, described above.

Preview button:  Opens the Print Preview window, displaying all of the reports selected on this dialog.

Print button:  Sends the selected reports to the printer, a Print Setup dialog will be displayed before printing to allow you to change the settings of the printer.

Cancel button:  Closes this dialog without generating any reports.

Report Category: General

Title page:  Lists the project title, client data, your company information, and includes an optional picture.

Project:  Lists data entered in the inputs on the Project, Client, Company and Design tabs of the General Project Data window, as well as Check Figures and total building heating and cooling loads.

Miscellaneous:  Lists design conditions for each system, duct sizing inputs, and infiltration and ventilation data for each system.

Quick Sales Proposal:  Shows all data specified on the Quick Sales Proposal window, including selected items from the General Project Data window, Equipment Specifications from the System Data window, and all of the entered Custom Text Blocks.

Project Bill of Materials:  Shows the print version of the Project Bill of Materials window, which shows a list of user-defined parts that may include those from an automatic takeoff of the ductwork you drew.

Report Category: Duct Sizing

Duct Size Preview:  Shows a summary of all the ducts that have been defined in the project, as shown in the Duct Size Preview topic.

Building Rotation Duct Sizes:  Generates a one page report (usually) that lists each room and duct in the project, showing the heating and cooling airflow requirements at each of the eight possible rotation directions.  Also shows the duct size for the rotation with the highest airflow.

Graphic Manual D Ductsize - Data:  Generates a report listing each duct that you created in Drawing Board with the Manual D Ductsize Drawing Objects catalog.  Includes the duct diameter, width, height, velocity, pressure loss, etc..

Graphic Manual D Ductsize - Pressure Changes Graph:  Generates a separate graphical report for each duct system that shows the static pressure and total pressure for each duct along the path with the highest static pressure loss.

Tabular Manual D Ductsize - Grid:  Shows the duct tree grid from the left hand side of the Tabular Manual D Ductsize window, which shows all of the ducts and how they are connected to each other.

Tabular Manual D Ductsize - Data:  Same as the equivalent report described above for Graphic Manual D Ductsize, but uses data from the Tabular Manual D Ductsize window instead.

Tabular Manual D Ductsize - Pressure Changes Graph:  Same as the equivalent report described above for Graphic Manual D Ductsize, but uses data from the Tabular Manual D Ductsize window instead.

 

Report Category: Building

Load Preview:  Displays the grid from the Load Preview window, which shows gain, loss and CFM values for the building and each system, zone and room in the project.

Summary Loads Report:  Generates a table that shows the gain and loss values of each floor, roof, wall, glass and door, as well as other loads such as people and infiltration.

Building Rotation General Overview:  Generates a two or three page report that lists airflow and cooling load data for each room and for the entire building.  Includes a graph that shows the building tonnage at each rotation as well as a graph that shows the building hourly net gain for each possible rotation.

Building Loads Pie Chart:  Generates a single page report with two pie charts:  one showing the heating loads of various items in the project, and other showing the cooling loads.

Building Loads Bar Chart:  Shows the same data as the Building Loads Pie Chart report (above), but displayed in a three dimensional bar chart.

ACCA Form 310 (Filled In):  Shows the ACCA Form 310 report, which includes the values filled in from the current project using the ACCA Form 310 Data window.

ACCA Form 310 (Blank):  Same as above, but prints the form in its original state, with none of the blanks filled in.

Report Category: System

Summary Loads Report:  Generates a table that shows the gain and loss values of each floor, roof, wall, glass and door, as well as other loads such as people and infiltration.

Room Load Summary:  Generates a report for each system in the project that includes a table showing each room's loss and gain, CFM requirements and duct sizes, subtotaled by zones and showing the total values for the system.  Includes a Cooling System Summary showing the Net, Recommended and Actual tonnages for the system, as well as the sensible to latent splits.  Shows cooling and heating Equipment Data entered in the System Data window's Equipment Specifications inputs.  If you checked the "This system's equipment was selected in accordance with ACCA Manual S" box on the Equipment tab of the System Data window, this report also includes a Manual S section.

Equipment Data:  Lists the data for the heating and cooling equipment selected for each system, including the model number, type of system, capacity, etc..  If you checked the "This system's equipment was selected in accordance with ACCA Manual S" box on the Equipment tab of the System Data window, this report also includes a Manual S section.  This report may also include equipment pictures, if specified and if the "Print Pictures on Equipment Data Report" box below this row is checked.

Print Pictures on Equipment Data Report:  If pictures have been specified for the selected equipment, shows them on the Equipment Data report, described above.

Manual S Performance Data:  Shows a report listing each system's design conditions and loads, and summarizes the results from the data you entered on the Manual S Cooling Performance Data window.  Alternatively, you can enter your adjusted data (adjusted capacity, adjusted sensible capacity and adjusted latent capacity) on the Equipment tab of the System Data window.  If the data from the Manual S Cooling Performance Data window are all blank then your adjusted capacity values from the Equipment tab of the System Data window will be used on this report instead.  If you do fill in those values manually make sure the sensible plus latent equals the total.

AED Test (Adequate Exposure Diversity):  Displays a chart showing the hourly glass load compared to the average glass load over a period of 13 hours.  Defines Adequate Exposure Diversity and shows the percent difference between the peak hour glass load and the average.

Psychrometric Chart:  Uses components from Elite Software's PsyChart program to generate an accurate, altitude-adjusted, psychrometric chart showing the points and processes involved for each cooling system in the project.

System Loads Pie Chart:  Generates a single page report with two pie charts:  one showing the heating loads of various items in the project, and other showing the cooling loads.

System Loads Bar Chart:  Shows the same data as the Building Loads Pie Chart report (above), but displayed in a three dimensional bar chart.

Hourly Room Net Gain:  Shows the hourly net gain of each room in the system from 8 a.m. to 7 p.m..  You can use this graph to help you decide how to assign zone numbers to rooms (if zoning equipment will be used).

RPER 1.01 ACCA Design Review Form (IRC - Filled In):  Shows the ACCA form entitled, "Residential Plans Examiner Review Form for HVAC System Design (Loads, Equipment, Ducts)," which includes the values filled in from the current project and the current system using the RPER 1.01 ACCA Design Review Form Data window.  This version of the form has headers that reference sections in the IRC (International Residential Code).

RPER 1.01 ACCA Design Review Form (IRC - Blank):  Same as above, but prints the form in its original state, with none of the blanks filled in.

RPER 1.01 ACCA Design Review Form (UMC - Filled In [or Blank]):  Same as the IRC versions of the form, described above, but the headers reference sections in the UMC (Uniform Mechanical Code).

Note:  By default, the ACCA form is generated using a scale factor that adjusts everything so that the text at the bottom of the form is a little farther from the bottom edge of the paper than the original document produced by ACCA, in order to accommodate printers with a smaller printable area that does not extend as far down the page.  The default for the scale factor is 0.98.  If you would like to change the scale factor to stretch things farther, one way or another, you can enter the following in the "[Miscellaneous]" section of your Rhvac9.ini file:

ACCAReportYScale=0.95

The above example uses 0.95, but you can use 0.97, 1.00, or whatever you want.  The default is 0.98.

Energy Star Form (Filled In):  Shows the Energy Star form entitled, "HVAC Design Report, ENERGY STAR Certified Homes, Version 3 / 3.1 (Rev. 08)," which includes the values filled in from the current project and the current system using the Energy Star Form Data window.

Energy Star Form (Blank):  Same as above, but prints the form in its original state, with none of the blanks filled in.

Report Category: Zone

Summary Loads Report:  Generates a table that shows the gain and loss values of each floor, roof, wall, glass and door, as well as other loads such as people and infiltration.

Zone Loads Pie Chart:  Generates a single page report with two pie charts:  one showing the heating loads of various items in the project, and other showing the cooling loads.

Zone Loads Bar Chart:  Shows the same data as the Building Loads Pie Chart report (above), but displayed in a three dimensional bar chart.

Report Category: Room

Detailed Room Loads:  Generates a one-page report for each room in the project that includes the runout duct size and other duct sizing information, infiltration and ventilation values, and detailed gain and loss data for each floor, roof, wall, glass and door in the room.

Bar Chart:  Generates one report showing the cooling and heating loads of each room, and another that shows the sensible and latent cooling loads of each room in the project.

Radiant Floor:  Generates a report that shows the radiant floor results for each room for which you have entered data on the Radiant Floor Properties dialog.
