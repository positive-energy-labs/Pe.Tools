Create Room With Generic Defaults

This message box opens if you try to drag and drop a Room/Walls object onto the drawing while the Default Room Data window has one or more important defaults left blank or zero.  For example, if you have not entered a default room height, the below dialog will open.  But leaving the room length and width at zero will not trigger opening the dialog.

 

 

Yes Button:  For each item listed on this dialog as being blank or zero on the Default Room Data window, Rhvac will insert some generic default data into those inputs.  For example, if you leave the room height on the Default Room Data window at zero, the message shown in the above screenshot will be shown ("Room height is zero"), and if you click Yes, the generic default of 8 feet will be inserted into the Default Room Data window's Height input, and the new room will have a height of 8 feet.

 

No Button:  Creates the room with the blank or zero items listed still being blank or zero.  For example, if one of the listed items on this dialog says, "Wall material is blank," then the walls of the newly created room will all have the Wall Material property set to be blank.

 

Cancel Button:  Closes this dialog without creating a new room or making any other changes.

 

Help Button:  Opens this Rhvac 10 Help window, and goes to this topic.
