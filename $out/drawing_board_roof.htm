Roof (Rhvac Drawing Objects, Chvac Drawing Objects)

The Roof figure allows you to add multiple roofs to a room (or zone in Chvac).  You must drop a Roof directly onto the background of the room that you want it to be in.  Note that it is not necessary to add a Roof figure to a room if the room has only one roof and that roof’s projected (horizontal) area is the same as the room area.  If that is the case, you can use the Intrinsic Roof Special Properties of the room to define the Roof material and other properties.

Note that if the roof is sloped, you can enter the pitch in the Slope input on the Special tab of the Object Properties window.  The actual area of the roof will be determined by the area on the drawing and the slope that you enter.

Kneewalls:  Set the Kneewall property for a Wall object to True in order to handle kneewalls.  Doing that will make it so you can select a roof material for that Wall object's Material property.

Partition Roof/Ceiling:  Enter a value in the Roof STD and Roof WTD properties in order to make the roof into a partition roof.  These properties are also available for the Room object's Intrinsic roof.

Special Commands

Edit Roof Polygon:  Opens the polygon of the Roof to allow you to define the individual points that make up the polygon.  When in editing mode, click and drag anywhere on the polygon to create a new point.  To move an existing point, click on the point and drag it to a new location.  Hold down the Ctrl key while dragging a point to make the point snap to the grid.  To delete a point, click on the point and press the backspace key.  When you are finished editing the polygon, right click in a blank part of the drawing and click, "Close Open Object" from the popup menu.

Delete:  Removes this Roof from the room.
