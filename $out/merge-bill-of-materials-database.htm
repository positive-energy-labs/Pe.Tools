Merge Bill of Materials Database (Bill of Materials - General Menu)

After installing an update and then opening Rhvac, if there is new Bill of Materials data available, you may see the following message box asking whether you want to open the Merge Bill of Materials Database window so you can then merge the new data with your existing database.

 

If you click "Yes" on the message box, the below window will open.  If you click "No" on the message box, you may open the below window while the Project Bill of Materials window is open by clicking the menu, "Bill of Materials - General | Merge New Data."

 

Changes in this Version of the Database:  Shows the changes that have been made to the database.  This information helps you decide whether or not to merge the new data with your database.  If there is no new data available, this box will say so.

 

Perform Merge:  Merges the new data with your database.  This button is only enabled if there is new data available.  The merge process takes several seconds to complete, then a "Merge Complete" message box opens and says that the merge is complete.  Upon clicking OK, the Merge Bill of Materials Database window will close.

 

Help:  Opens this topic in the Rhvac 10 Help window.

 

Close:  Closes this window without making any changes to your database.
