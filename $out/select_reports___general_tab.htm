Navigation:  Program Windows > Other Windows > Select Reports >

Select Reports - General Tab (File Menu)

Icon: .  Keyboard Shortcut:  CTRL+P

Opens the Select Reports dialog, allowing you to select reports to be printed or previewed, and to set various options regarding the appearance of the reports.

Click another tab on the picture below to go to help on that tab.

Add a date stamp footer to each page:  Puts today's date at the bottom right hand corner of each page of the report.

Show page numbers in the page header:  Puts a page number in the right side of the page header at the top of each page.

Include program icon in page header:  Displays the program icon in the middle of the page header.

Create an HTML file:  Generates an HTML file that is similar in appearance to the reports.

Show Net tonnage:  Shows cooling tonnage values as sensible+latent.

Show Recommended tonnage:  Shows cooling tonnage values that meet both the sensible and latent gains of the project, according to each system's Percent Sensible Capacity.

Default to Whole Page view:  Makes the Print Preview open with the entire page visible.  If unchecked, the default view is Page Width.

Print graphs in color:  When checked, prints the graphs in solid colors.  When unchecked, prints graphs in black and white, using different patterns for the graph elements.

Create an RTF file (folder name below):  Generates an RTF (Rich Text Format) file whenever print preview reports are generated.  The folder  in which the file is created is specified in in the HTML and RTF Folder input at the bottom of this dialog.

Include project filename on Project report:  Makes it so the report named the "Project Report" includes a line showing the filename of the current project.

Add a filename footer to each page:  Prints the name of the current project filename at the bottom left of each page of the report (except the title page).

Include hourly total net gain line on AED Report:  When checked, shows an additional line representing the total hourly load above the one showing the fenestration gain on the AED Report.  When unchecked, only the fenestration gain is plotted.  When the total line is not include it makes the variations in load more pronounced.

Use System Air Type = Auto for Building Rotation Report:  When checked, makes it so when you include the Building Rotation Report it will show minimum system and room airflows rather than the value entered in the System CFM input on the Design tab of this window.  That makes it so you can see the minimum required room CFM values for the various rotations.

Use black text in the body of grid-style reports:  When checked, only black text (and sometimes a gray background) is used for each of the grid-style reports, including the Load Preview Report and the Building Rotation.  This feature can be helpful if your printer is unable to print text unless it is colored black.

Show air turnover rate in Check Figures section:  When checked, includes the "air turnover rate" within the Check Figures sections of various reports.  This quantity represents the number of times per hour the volume of the conditioned space passes through the system fan.

Include page border:  When checked, report pages include a border around the edge.

Include "ACCA Approved" notes on title page:  When checked, adds two lines stating that Rhvac is an ACCA approved Manual J and Manual D computer program.  These same notes always appear on other reports, but if you need them to show up on the title page too, then check the box.

Show winter outdoor relative humidity on Project Report:  When checked, shows the calculated winter outdoor relative humidity in a table on the Project Report.  When unchecked, shows "n/a" instead.  The default value for winter relative humidity is 80%, since that is what Manual J assumes in the winter, for purposes of calculating the load due to winter humidification.  If you want to change the winter outdoor relative humidity you can change the winter wet bulb input on the Design Conditions tab of the General Project Data window.

Include company street address in page header:  When checked, adds the company address from the license file to the 3rd line on the left side of the page header, before the company city, state and ZIP.

HTML and RTF folder:  Displays the name of the folder where the file will be created if the Create an HTML file option is checked in the list above.  The file will have the same base name as the current project, but will have the extension HTM.

Add notes if using custom building volume:  Makes it so if you selected Custom for the Building Volume Option on General Project Data an asterisk is added to building, system, zone and room volumes, followed with a note that states the volume is based on custom building volume.

Show calculated total volume also if building volume option is custom or above grade:  If you have the Building Volume Option set to Above Grade or Custom, checking this box makes it so places in the reports that show volume will have an additional line added that shows the total, calculated volume.

Preview button:  Opens the Print Preview window, displaying all of the reports selected on this dialog.

Print button:  Sends the selected reports to the printer, a Print Setup dialog will be displayed before printing to allow you to change the settings of the printer.

Cancel button:  Closes this dialog without generating any reports.
