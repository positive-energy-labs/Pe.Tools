Duct Popup Menu Commands (Manual D Ductsize Drawing Objects)

Here is the list of commands available for graphic Manual D Ductsize ducts from the right click popup menu.  To access these commands, right click on a duct object on the drawing.  Most of these commands are available for all ducts, but some of them are only available for trunks and some only for runouts.  Most of them are located in sub menus off the main popup menu; the ones that aren't are listed last.  Also see the Duct Shortcut Keys topic.

General Duct Settings

Duct Defaults for this System:  Opens the Duct Defaults for System 1 dialog, where you can enter default values for trunks and runouts, default fittings, and define your global default scenarios.

Set Multiple Duct Properties:  Opens the Set Multiple Duct Properties dialog, where you can set one or more properties for multiple ducts on the drawing.

Duct Appearance Options:  Opens the Duct Appearance Options dialog, where you can set a few of the yes/no properties that only affect the appearance of the ducts.

Manual D Ductsize Drawing Colors:  Opens the Manual D Ductsize Drawing Colors dialog, where you can set the default colors that are used for the various kinds of ducts on the drawing.

Set Register Sizing Data for this System:  Only available in the General Duct Settings menu of trunk objects.  For runout objects this item is in the Register Options menu.  Opens the Register Sizing Data dialog that lets you set the parameters of the automatic duct sizing for runout ducts in the current system.  Automatic register sizing only takes place during recalculation.

Find Duct:  Opens the Find Duct dialog, which makes it easier to locate a particular duct on a large drawing.

Fittings:  Opens the Fittings dialog, which lets you select the ducts assigned to the Fittings property of the selected duct.

Reapply System Defaults to this Duct:  Copies the defaults for trunks or runouts that have been defined for the system to the current duct's properties, overwriting their current values.  This item is only available if the selected duct is connected to a system that includes a main trunk object.  This feature is useful if you have changed the default settings after having connected a particular duct to the system.

Set Initial Duct Length:  Opens an Initial Duct Length dialog to let you enter the initial duct length whenever you drag and drop a duct object onto the drawing.  This feature is just for convenience.

Delete Multiple Ducts:  Opens the Delete Multiple Ducts dialog, where you can delete multiple ducts at once.

Junction Fitting

Show Junction Fitting for this Duct:  Toggles whether or not the junction fitting polygon is drawn for the current duct.  Also sets the "Show Junction Fitting" property.

Set Junction Fitting Legs to Zero for this Duct:  Sets the values of the following properties to zero for the current duct:  "Junction Fitting Leg Length" and "Junction Fitting Excess Width."

Set Junction Fitting Legs to Default for this Duct:  Sets the values of the following properties to reasonable default values for the current duct:  "Junction Fitting Leg Length" and "Junction Fitting Excess Width."

Show Junction Fitting for all Ducts:  Sets the "Show Junction Fitting" property for all trunks on the drawing to True.

Hide Junction Fitting for all Ducts:  Sets the "Show Junction Fitting" property for all trunks on the drawing to False.

Set Junction Fitting Legs to Zero for all Ducts:  Sets the values of the following properties to zero for all ducts on the drawing:  "Junction Fitting Leg Length" and "Junction Fitting Excess Width."

Set Junction Fitting Legs to Default for all Ducts:  Sets the values of the following properties to reasonable default values for all ducts on the drawing:  "Junction Fitting Leg Length" and "Junction Fitting Excess Width."

Downstream Branch Fittings

Assign Default Takeoff Fittings to Downstream Branches:  Assigns the default fittings defined in the Takeoffs category of the Default Fittings dialog to each of the ducts connected downstream of the current duct.

Assign Default Junction Fittings to Downstream Branches:  Assigns the default fittings defined in the Junction category of the Default Fittings dialog to each of the ducts connected downstream of the current duct.

Elbows/Breaks

Add Bend:  Adds a joint in the section of the duct where you clicked.  The joint is indicated by a new round yellow grab handle.

Remove Bend:  Removes the bend in the section of the duct that you clicked.  Any other existing sections on either side of the bend being removed join each other.

Break Duct Here:  Breaks a trunk into two separate trunks at the point where you right clicked.  This command is only available for trunks, and only works if the place where you clicked was at least a couple of feet away from any endpoints or bends in the trunk.

Merge with Downstream Duct:  Merges a trunk with the trunk connected to it downstream.  This command is only available if there is only one downstream trunk connected to the trunk you right clicked.

Realistic Elbows

 

Show Realistic Elbows for this Duct:  Makes it so any elbow fittings assigned to this duct that are capable of being drawn realistically will be drawn that way.

 

Turn Off Realistic Elbows for this Duct:  Makes it so all elbow fittings assigned to this duct are drawn simply as hard bends in the duct.

 

Show Realistic Elbows for All Ducts:  Makes it so any elbow fittings assigned to ducts on the drawing that are capable of being drawn realistically will be drawn that way.

 

Turn Off Realistic Elbows for this Duct:  Makes it so all elbow fittings assigned to ducts on the drawing are drawn simply as hard bends in the duct.

Register Options (Runout Objects Only)

Rectangular Register, Round Register:  Changes the Register Shape property.  These commands only affects the appearance of the object on the drawing.

Rotate Register 90°:  Assigns the value of the Register Width property to the Register Height property and vice-versa.  This command is only available if those two properties are not equal.

Set Register Sizing Data for this System:  Only available in the Register Options menu of runout objects.  For trunk objects this item is in the General Duct Settings menu.  Opens the Register Sizing Data dialog that lets you set the parameters of the automatic duct sizing for runout ducts in the current system.  Automatic register sizing only takes place during recalculation.

Flow Arrow Up [Down, Left, Right]:  Turns on or off a flow arrow indicating the lateral directions in which the vanes on the register will be slanted to direct the air.  You can adjust the size of the flow arrows with the Flow Arrow Scale property.

Plug Runout into Nearest Trunk:  Moves the upstream end of the runout to the nearest available Supply Trunk or Supply Main Trunk object on the current sheet and attempts to plug the runout in to it.  This command does the same thing as checking the AutoConnect checkbox on the Auto-Create/Refresh Runouts dialog at the time that runouts are created.  You should usually make such connections manually with drag and drop rather than using this command in order to have control over where each connection is made.

[In Main Popup Menu]

Help on [this] Figure:  Opens the Rhvac help file and goes to the topic for the type of duct you selected.

Exclude Upstream Junction Fitting Leg:  Makes it so the junction fitting polygon of the duct just upstream from the selected duct does not include a "leg" for the current duct.  Also sets the "Exclude Upstream Junction Fitting Leg" property to True.

Auto Create/Refresh Runouts:  Opens the Auto Create/Refresh Runouts dialog, where you can create or refresh the airflows of runouts for the Rhvac rooms on the drawing.

Resize Duct Systems:  Performs a recalculation of the project and updates all of the calculated duct sizes.  It is not necessary to use this command unless you need to see an immediate update of changes you have made on the drawing, since this function is executed automatically at certain times anyway, such as when the Drawing Board window opens or closes, when you generate reports, and when you open the Load Preview window.

Delete:  Removes this duct from the drawing.
