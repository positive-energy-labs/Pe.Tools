Navigation:  Program Windows > Other Windows > Select Reports >

Select Reports - Title Page Tab (File Menu)

Icon: .  Keyboard Shortcut:  CTRL+P

Opens the Select Reports dialog, allowing you to select reports to be printed or previewed, and to set various options regarding the appearance of the reports.

Click another tab on the picture below to go to help on that tab.

Picture:  Displays a thumbnail view of the selected picture to be shown on the title page.

Title page picture filename:  Specifies the full path and filename of the picture file to be used on the title page.  The allowed picture formats are:

bmp, wmf, emf, dib, ico, gif, jpg, dbp, tif, mdp, jpeg, cur

Picture Dimensions, Width, Height:  If you would like to restrict the picture width and height to be within a certain range, then enter the desired values here, in pixels.  If these inputs are left at zero, the title page picture will be printed at its default dimensions.  Note that whether you specify a width and height or not, the picture will be reduced in size to fit within the allotted space on the page whenever necessary.  Also note that windows metafile pictures (wmf) scale much better than do bitmaps (bmp).

Preview button:  Opens the Print Preview window, displaying all of the reports selected on this dialog.

Print button:  Sends the selected reports to the printer, a Print Setup dialog will be displayed before printing to allow you to change the settings of the printer.

Cancel button:  Closes this dialog without generating any reports.
