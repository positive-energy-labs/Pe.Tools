Supply Trunk

You will use this object for every supply trunk in the system that is not the main trunk.  Its upstream end is the small, filled in circle, while its downstream end is the larger, open circle.  To connect a supply trunk to another trunk, drag the upstream end to the downstream end of the upstream trunk.  Or you can drag the upstream end to the centerline of the upstream trunk, somewhere along its length (but not too close to an endpoint or a bend).  When this object is properly plugged in, its fill color changes.

Return Trunk

This object is virtually the same as the Supply Trunk object, but only works with other return ducts.
