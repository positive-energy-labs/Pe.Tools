General Project Data (Project Menu)

Icon: .  Keyboard Shortcut:  ALT, P, G

Opens the General Project Data window, where reference data, weather conditions and duct information can be entered.

Click another tab on the picture below to go to help on that tab.

Project Title, Designed By, Date:  These inputs are provided to let you document background information about the project.  This information will be printed on the Project report.

Note:  To insert today's date in the Date input, blank out all the text in this input and press the Backspace key.

Units:  Sets the units for the current project.  If you change this input after some inputs have already been entered, they will be converted to the new units setting.

Comment:  Allows you to enter any additional information about the project, which can optionally be printed on the General Project Data Input report.

Include this comment on reports:  Determines whether or not the comment will be printed on the Project report.

Orientation Comment (Parts 1 and 2):  If you are going to print the Building Rotation Report, use these two inputs to create your building orientation comment to indicate the original orientation of the house as entered.  In the first input enter "House," "Front door," or other text, then select the direction in the second input to complete the comment.

Permit Number(s):  Specifies any permit numbers you want to enter for the current project.  If you have multiple permit numbers you may want to put each one on a separate line, as shown in the above picture.  To create a new line, type Ctrl+Enter (hold down the Ctrl key and press Enter).
