Export EnergyGauge USA File (File Menu)

Icon: .  Keyboard Shortcut:  ALT, F, E, U

Opens the Create EnergyGauge USA FlaRes 2010 File dialog, where a file can be created for the EnergyGauge USA program.  The file created is in the ENB file format and can be imported into EnergyGauge USA by clicking its "Load *.enb File" button.

EnergyGauge USA folder:  Specifies the name of the folder where the ENB file will be created.

Browse:  Opens a Browse for Folder dialog, where you can change the folder where the ENB file will be created.

Existing EnergyGauge USA files in above folder:  Lists any files with the extension ENB that are in the selected folder.

EnergyGauge USA Filename to be created:  Specifies the full path and filename for the ENB file that will be created from the current project.

Format Options:

·Use current format and group materials and rooms in the same system together into one big room:  Uses the 2010 and later ENB format and creates only one space (room) per system in the ENB file.  Consolidates individual floors and roofs sharing the same construction material entered in multiple rooms into one big floor or roof for the system.  Walls, windows and doors remain as individual items just as they were entered in Rhvac.

·Use 2010 format and keep rooms as individual rooms as entered in Rhvac:  Uses the 2010 and later ENB format and creates a space (room) for each room entered in Rhvac.  Leaves floors, roofs, etc., as individual items just as they were entered in Rhvac.

·Use the old 2008 format:  When selected, generates an ENB file in the format of the previous version of EnergyGauge USA, which was called "EnergyGauge USA FlaRes2008."  Select this option only if you know the reasons for using the old format (e.g., you need to use the older version of EGUSA for HERS ratings).

Limits:  The EnergyGauge USA FlaRes 2010 program has the following limits on project file sizes, due to limitations in the DOE2 simulation size.

Maximum of 29 rooms for projects with 1 or 2 systems.

Maximum of 23 rooms for projects with 3 systems.

Maximum of 14 rooms for projects with 4 systems.

Maximum of 5 rooms for projects with 5 systems.

OK:  Creates the file and closes this dialog.

Cancel:  Closes this dialog without creating the file.
