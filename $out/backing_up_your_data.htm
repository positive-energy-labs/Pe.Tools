Backing Up Your Data

Backing up your data is very important so that you do not lose your important files in which you have invested a lot of time and work.  You should backup files to another media, such as a CD, flash drive, online drive, network server, etc..  It's also a good idea to keep some backup copies in a different location than your original files.

Which files and folders you should backup depends on the way in which your Elite Software programs are installed.  There are two possibilities:

Option A:  If you have a folder named "Advanced" in the Elite Software section of your Start menu, then you have Option A.  This should be the  case if the first Elite Software program you installed was compiled after about the beginning of the year 2010.  With this kind of installation you only need to backup the following two folders:

My Documents\Elite Software This folder contains all of your project files, which are in one or more sub folders.)

Public\Documents\Elite Software Data This folder contains any other potentially important files other than project files, such as databases used within Elite Software programs.

Note:  If your version of Windows is XP or earlier the location under Option A will instead be: Shared Documents\Elite Software Data  

Option B: This is the old style of installation.  If you do not have a folder named "Advanced" in the Elite Software section of your Start menu, then you have the Option B style of installation, which indicates that the first Elite Software program you installed was compiled before about the start of the year 2010.  With this kind of installation there are also two kinds of files to backup: project files and user-editable databases, such as a weather database.  The location of the projects will usually be one of the following:

C:\Program Files\Elite\[Program Name]\Projects

C:\Program Files\Elite Software\[Program Name]\Projects

where [Program Name] is something like "Rhvac."  The Program Files folder may instead be named "Program Files (x86)."

Under Option B, if you have multiple Elite Software programs you will need to locate multiple "Projects" folders.

The other files you should backup under Option B vary from one program to another.  For example, with the Rhvac and Energy Audit programs the weather database file is named "AudWthr.wdb" and under Option B is usually located in C:\Program Files\Elite\Common.  If you have an Option B style of installation and would like to know which other database files may be important to backup feel free to e-mail us at techsupport@elitesoft.com or call the technical support line at 979-690-9420.
