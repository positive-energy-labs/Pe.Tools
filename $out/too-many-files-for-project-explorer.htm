Too Many Files for Project Explorer

This dialog is shown if you have more than the maximum number of project files allowed to be shown in the multi-project version of the Project Explorer window.  This dialog will not be shown more than once while the multi-project Project Explorer window is open.

Default Maximum Number of Projects Shown = 1000

To Change Maximum:  To change the maximum number of projects shown in the Project Explorer, click the "Projects: [Number]" button in the Project Explorer window's toolbar.

 

Show this dialog when there are too many projects in one folder:  If you uncheck this box, this dialog will not be shown even if the number of projects is greater than the maximum number of projects that can be shown in the Project Explorer.

 

Help:  Displays the help topic for this dialog in the Rhvac 10 Help window.

 

Close:  Closes this dialog.
