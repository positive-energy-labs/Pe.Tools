General Project Data - Duct Sizing Tab

Icon: .  Keyboard Shortcut:  ALT, P, G  Also see the Duct Sizing Overview topic.

Opens the General Project Data window, where reference data, weather conditions and duct information can be entered.

Click another tab on the picture below to go to help on that tab.

Note:  All of the inputs on this tab (except for the schedule) are only used for the built-in duct sizing of runouts and system main trunks in Rhvac.  The inputs on this tab do not apply to ducts that you enter on the Tabular Manual D Ductsize  window or with graphic Manual D Ductsize, since those ducts will each have their own settings for these inputs.

Calculate:  Select whether or not you want to have main trunk or runout duct sizes calculated for this system.

Use Schedule:  Select whether or not to use the duct schedule entered to the right or to allow the program to size the main trunk or runouts for this system without restricting the sizes to those available in the schedule.

Rough Factor:  The material roughness factor is a number which describes the relative roughness of the duct material and affects the pressure loss of the air moving through the duct due to friction with the duct walls. How to add duct materials to the dropdown help list.

Pressure Drop:  Specify the desired pressure drop here and Rhvac will attempt to size the duct to achieve this pressure drop.

Min. Velocity, Max Velocity:  Enter the desired minimum and maximum main trunk or runout air velocity constraints here.  ACCA Manual D lists 500 ft./min as a recommended value and 750 as a maximum value for runout duct air velocities.

Min Height, Max Height:  The minimum or maximum height refers to either the diameter or the height of the duct, depending on whether the shape is round or rectangular.  If there are no height constraints these inputs may be left as zero.

Shape:  Choose the shape that best describes the type of ductwork being used for the main trunk or runout ducts for this room.  If you have chosen to use the duct schedule, Rhvac will select from either the Round Duct Schedule or the Rectangular Duct Schedule based on this input.

CFM/Runout:  Enter the amount of airflow which you want Rhvac to distribute to each runout in the rooms in this system for the built-in duct sizing.  The number of registers for each room will then be calculated based on the room's total CFM requirement.  Note that if you leave this field as zero on both the System Data and Room Data windows and you don't specify a number of registers greater than zero on the Room Data window, Rhvac will assume 1 register for the room.

Common Schedule:  Specifies the sizes that you want the program to pick from when it determines the main trunk or runout diameters or widths.  If the ducts are rectangular, the schedule refers to the width of the duct, while if the ducts are round, the schedule is one of diameters.  Note that these schedules can be used for any ducts in the current project, whether with the built-in sizing of runouts and main trunks in the Rhvac project, the ducts you create on the Tabular Manual D Ductsize window, or duct objects that you draw on Drawing Board with graphic Manual D Ductsize.  

You may have as many schedules as you like.  Use the Add Schedule button in the toolbar to the right of the "No." input to add a schedule to your project.  If you are using the built-in duct sizing and you set the Use Schedule inputs to Yes, then schedule number 1 will be used.  For Manual D Ductsize and Tabular Manual D Ductsize, if you set the Sizing Method property of a duct to Schedule, then you should also set the Schedule Number property to the schedule you want to use.
