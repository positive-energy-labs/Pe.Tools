Weather Database (Tools Menu)

Icon: .  Keyboard Shortcut:  ALT, T, W

Opens the Weather Database window, where you can edit the global database of weather data for thousands of cities.  If your city is not included in the list, you can add it, and you can edit the data for any existing city in the list.  Note that whenever you edit the data for a city, any Rhvac projects that you later reference for weather data will be affected by the changes you make, but existing Rhvac projects will not be affected unless you go to the General Project Data's City input and retype the city name, which will bring in the new data from the database.

Note:  Many of the inputs on the Weather Database window are not used in Rhvac and are not covered in this help reference.
