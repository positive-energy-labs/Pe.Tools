Wall (Rhvac Drawing Objects, Chvac Drawing Objects)

The Wall figure is a LineShape, which means that you can drag either of its endpoints and the wall will stretch as you drag it.  A room consists of a Room figure and several Wall figures that remain attached to each other as they are repositioned.

Kneewalls:  Set the Kneewall property for a Wall object to True in order to handle kneewalls.  Doing that will make it so you can select a roof material for that Wall object's Material property.

Special Commands

Divide Wall:  Divides the wall into two walls of equal length.  See the Special Keystrokes section below.

Remove Wall:  Removes the wall from the collection of walls in the room.  Note that it is not possible to remove a wall unless there are more than four walls present in a room.  When you remove a wall, the walls that had been attached to its endpoints attach themselves to each other.

Include Wall:  Toggles the status of whether the wall will be included in the HVAC calculations.  This menu is checked if the wall is included and unchecked if not.  Setting the Include Wall property to True automatically sets the Hide Wall property to False.  See the Special Keystrokes section below.

Hide Wall:  Toggles the status of whether or not the wall is hidden (drawn with a Line Color of white).  Setting the Hide Wall property to True automatically sets the Include Wall property to False.  This menu is checked if the wall is hidden and unchecked if not. See the Special Keystrokes section below.

Note:  The Include Wall and Hide Wall properties make it so a Wall object can be in one of three states:

1.The wall is included in the calculations (Included = True, Hidden = False)

2.The wall is not Included in the calculations, but its outline is visible (Included = False, Hidden = False)

3.The wall is not included in the calculations and its outline is not visible (Included = False, Hidden = True).

Paste Glass:  Creates a new window or glass door in the current wall at the point where you right clicked.  This item is only available if you have previously copied a glass into the clipboard with the Copy Glass command.

Paste Door:  Creates a door in the current wall at the point where you right clicked.  This item is only available if you have previously copied a door into the clipboard with the Copy Door command.

Special Keystrokes

Double click:  Toggles the status of the Included property.

Ctrl+Double Click:  Divides the wall into two walls.  The wall is divided at the point where you double click the mouse.  For any room that is not rectangularly shaped or that includes bay windows, etc., you will need to divide walls using this command.

Shift+Double Click:  Toggles the status of the Hide Wall property.
