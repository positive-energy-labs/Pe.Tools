Single, Double and Roll-Up Door (Rhvac Drawing Objects, Chvac Drawing Objects)

To add a door to the drawing, drag the the Single Door or Double Door icon from the Catalog Browser and drop it onto a wall.  Once a door is placed in a wall it cannot be moved to another wall.  If moved outside of its wall, the door figure will reposition itself back into the wall. The door is a LineShape figure, which means you can drag either of its endpoints and the door will stretch as you drag it.  

A door has several Special Properties, which you can enter on the Special tab on the Object Properties window.  Note that if the wall that the door is located in has its Included property set to False, the door will not be included in the program's calculations either.

The middle yellow handle lets you drag the door in a parallel manner along the length of its parent wall.

Special Commands

Swap Hinge Side:  Changes the side that the door hinge is on. This command is available only on the single door type of figure.

Reverse Swing:  Changes the door figure so that the door opens to the outside instead of the inside, or vice-versa.

Single Door, Double Door, Roll-Up Door:  Sets the appearance of the door figure to either single or double.

Delete:  Remove the door from the wall.

Copy Door:  Copies the selected door to the clipboard, so you can later paste it into another door or into a Wall object.

Paste Door:  Pastes the properties of the door that is in the clipboard into the current door.  Only available if you have previously copied a door by clicking the Copy Door command.  This command is also available in the Wall object's popup menu.

Special Keystrokes

Double Click:  Reverses the swing of the door.

Ctrl+Double Click:  Swaps the hinge side for the Single Door figure.
