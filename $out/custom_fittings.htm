Custom Fittings (Manual D Duct Sizer, Graphic Manual D Ductsize)

You can open the Custom Fittings dialog by clicking the Custom Fittings button at the bottom of the Fitting Selector dialog.  Custom fittings can apply to both the Manual D Duct Sizer window and to ducts drawn with graphic Manual D Ductsize.

Add button:  Opens the Add Custom Fitting dialog, which lets you define all the characteristics of a new, custom fitting.

Edit button:  Opens the Edit Custom Fitting dialog, which lets you modify some of the characteristics of a custom fitting you have previously created.  This button is only enabled if you have selected a fitting in the list.

Delete button:  Deletes the currently selected custom fitting from the list.  This button is only enabled for fittings that are not in the current project, as indicated by the "In Current Project" column.  The background color of fittings that occur in the current project is pale green.

Close button:  Closes this dialog without making any further changes.
