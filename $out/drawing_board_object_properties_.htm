Object Properties (Format Menu)

Icon:  Keyboard Shortcut:  ALT+O+R

Displays the Object Properties window, where a wide variety of properties can be set for selected objects on the drawing.  Property names are listed on the left side, while property values are on the right.

Standard tab:  Lists properties such as the layer that the object is on, its position and size.

Special tab:  Lists Smart Figure properties usually related to the calculations.

Appearance tab:  Lists properties that affect the appearance of objects, such as Fill Color and Line Style.

Font tab:  Lists properties related to the font of Text objects.  If an object includes no Text objects this list is blank.

Default property value:  Shown in blue in parenthesis immediately after the property name on the left hand side of the list.

Read only property:  Shown with the property value in blue.

Hidden property:  Shown with the property name in square brackets.  The property value may or may not be read only.  To toggle the visibility of hidden properties, hold the Ctrl key down and right click inside the list.
