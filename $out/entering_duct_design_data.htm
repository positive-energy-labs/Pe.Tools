Entering Duct Design Data (Tutorial Step 5)

                               

Now let's continue to the last step of the General Project Data window, which is entering the duct sizing information.  Note that the duct sizing inputs here (except for the schedule) apply only to the automatic room duct sizing that is included with Rhvac, NOT to the graphic Manual D Ductsize program.

1.Click the Duct tab and in the Main Trunk column, click the Rough.fact input's dropdown help button.

2.In the dropdown help window titled "Material Roughness Factor" click on the first item in the list, which says "Fiberglass Duct Board".  The number 0.003 is inserted into the input.

3.Now click on the down arrow button beside the Rough.fact input in the Runouts column.  In the "Material Roughness Factor" dropdown help window, click the item "Flexible Duct".  The number 0.01 is inserted into this input.

4.In the Main Trunk column, click the dropdown help button beside the Press. drop input.  The "Duct Pressure Drop" dropdown help window appears.

5.In the "Duct Pressure Drop" window, click the only item in the list, 0.1.  The number 0.1 is inserted into the input.

6.Repeat the previous step for the Press. drop input in the Runouts column.

7.In the Runouts column, click the down arrow beside the Avg. CFM per runout input.  The "CFM Per Runout" dropdown help window appears.

8.In the "CFM Per Runout" window, click the item that says 110.  The number 110 is automatically inserted into the input.

9.In the Schedule area, click the dropdown help button to the left of the first schedule entry.  The "Duct Schedule" dropdown help window appears.

10.In the "Duct Schedule" window, click the first schedule in the list.  The 40 schedule inputs will be filled in with the sizes from the selected duct schedule.

11.Close the General Project Data window.
