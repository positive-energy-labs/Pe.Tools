Global Dimension Change (Room Menu)

Icon: .  Keyboard Shortcut:  ALT, R, C

Opens the Global Dimension Change dialog, where you can set the dimensions of various things for multiple rooms at once.

Rooms:  Determines which rooms to apply the change to.  Check the box beside each room that you want to include.

Mark All, Clear All:  Checks or unchecks all of the rooms in the list.

Dimensions to Change inputs:  Specifies which dimensions to change and what to change them to.  Check the box and enter a dimension value for each kind of dimension you want to change in your selected rooms.

Perform Change button:  Makes the desired changes to the project.

Close button:  Closes this dialog.
