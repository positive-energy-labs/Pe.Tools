Duct Surface Area Calculator

To open this dialog, click the dropdown help button beside the Duct Surface Area input on the Duct Load Factors dialog (displayed from clicking the dropdown help button on the System Data window's Duct Load Factors input.

Floor Area:  Displays the floor area of the current system.  This value is used in the formula shown to determine the values for SA and RA.

No. Returns:  Displays the number of returns in the system.  Defaults to 2, but you can change it to any value you want, but note that you should limit the number of returns for this formula to 5 if there are more than 5 returns in the system.

SA, RA:  Specifies the Supply Duct Area and Return Duct Area, respectively.  The values in these inputs change automatically to show the results of the formula as you change the inputs to the left.

OK Button:  Saves your changes and copies the values of SA and RA back to the Duct Load Factors dialog.

Cancel Button:  Closes this dialog without making any changes.
