[Export] From Drawing:  Icon: .  Keyboard Shortcut:  None

Below are the picture file types that can be imported into Drawing Board:

DXF - AutoCAD 10, 14:  DXF file that is compatible with version 10 or 14 of AutoCAD.  See the DXF Conversion Guide topic for more information on importing DXF files.

Windows Metafile:  WMF file that is commonly used in many Windows applications.

Enhanced Metafile:  EMF file sometimes used in Windows applications.

Bitmap:  BMP file that is of a very common format compatible with Microsoft Paint and other programs.

MetaDraw:  MDP file format proprietary to the MetaDraw control from Bennet-Tec Information Systems (www.bennet-tec.com).
