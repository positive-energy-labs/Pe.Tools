Custom Roof Dialog

Click the Create Custom button on the Roof Material dialog to open this dialog.

Type:  Determines the list in which this custom roof will appear on the Roof Material dialog.

Const. Code (Construction Code):  Specifies the code that will appear on the Room Data window and the reports when you select this roof.  You can enter any text you want for the construction code, up to 20 characters, but the first character must not be a number.

U-Value:  Specifies the u-value of this roof or roof-ceiling combination.

CLTD Index:  Specifies the CLTD table to be used when looking up the cooling temperature difference used in finding the sensible gain of the roof.  Use the examples of the standard roofs shown in the dropdown help list to select an appropriate value.

Description:  Specifies the text used to describe this roof on the Roof Material dialog as well as the reports.

OK Button:  Adds your new custom roof to the list of custom roofs.

Cancel Button:  Closes this dialog without adding a custom roof.
