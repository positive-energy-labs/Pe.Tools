Importing a Floor Plan PDF Image

Importing a floor plan background makes things a little easier, so you can draw your Rhvac rooms right on top of the floor plan.  The most common kind of floor plan to use in Drawing Board is an image from a PDF file.  With such images, it is important to bring in the image in a way that keeps the project file size small.  

You can convert an image to monochrome automatically, using the Image Conversion dialog.  These steps show you how to do that conversion manually, if you are not satisfied with the automatic conversion to monochrome.

These steps are given in videos number 2, 3 and 8 on the following page:

https://www.elitesoft.com/pub/videos/db/importfiles2/dbimportfilestoc.html

1.Have the Drawing Board window open in a project that you have already started.

2.Create a sheet for the floor plan background that you will be importing by clicking the menu, "Format | Sheets".  Add a sheet named something like, "First Floor Background".

3.While still on the Sheets tab of the Drawing Properties window, add another sheet for the Rhvac room objects you will be drawing later.  Name it something like, "First Floor".  Check the Active box for the "First Floor Background" sheet, then click OK.

4.Open the PDF file you want to import in your PDF viewing program, such as Adobe Reader.

5.Take a snapshot of the floor plan and copy it to the clipboard.

6.Open the Paint program.

7.Paste the image into Paint.

8.In Paint, click "File | Save As," then set the file type to Monochrome Bitmap.  Select Desktop as the folder, and enter "Junk" as the filename (since the actual file is not important).

9.After saving the image as a monochrome bitmap named, "Junk," select everything with "Select All," then copy the image to the clipboard.

10.Bring Rhvac back to the front, and with the Drawing Board window open, click "Edit | Paste".  

11.Resize the image horizontally and vertically so that it matches the coordinate system in Drawing Board.

12.Select "Format | Sheets" and check the Active box for the First Floor sheet, then click OK.

13.Proceed with drawing your Room objects on top of the floor plan image.
