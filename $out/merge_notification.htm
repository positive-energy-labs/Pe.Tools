Merge Notification (At Program Startup)

Whenever you install an updated version of Rhvac that includes updated Equipment Picture Database information, a file is copied to your hard disk that contains all of the new data so that you can merge it in with your existing database if you want to.  The file that contains the new data is named "EquipPic.new" and is located in your C:\Elite\Common folder.  If this file is present when you open Rhvac, the above Merge Notification window will appear to let you know that the new data is available.

If you want to go ahead and perform the merge click the Merge button.  Otherwise click Cancel.  You can still perform the merge later by opening the Equipment Picture Database window and clicking the Merge button in its toolbar.  Once you do that, the Merge Notification will no longer appear (unless you later install another Rhvac update that has newer equipment picture data).  After you perform the merge, the "EquipPic.new" file will be renamed to "EquipPic.new.Merged" which you can delete if you want to.

If for some reason you do not want to perform the merge operation on your Equipment Picture Database, you can prevent the above window from opening at program startup by unchecking the "Show Merge Notification at startup when needed" option on the Rhvac Options dialog.
