Options (Tools Menu)

Icon: .  Keyboard Shortcut:  ALT, T, O

Opens the Rhvac Options dialog, where you can set custom preferences for Rhvac.

Click another tab on the picture below to go to help on that tab.

Recent files:  Sets the number of recently opened files displayed at the bottom of the File menu.

Save Reminder:  Determines whether or not to show the Save Reminder dialog at the specified interval.  If you check this input, enter the number of minutes that you want to elapse before you are reminded to save your work.

Show large file dialog:  Determines whether or not to show the Reduce Large File Size dialog when you save a project that is too large.

"Too large" file size:  Specifies the file size, in MB, to use as the minimum to trigger showing the Reduce Large File Size dialog.

Show current-project Project Explorer at startup:  Displays the Project Explorer for the current project when the program first opens.  The title of the window will be Project Closed if there is no open project.

Show multi-project Project Explorer at startup:  Displays the multiple project Project Explorer when the program first opens.

Default new projects to Room Data window mode:  Makes it so when you start a new project, it is not in Drawing Board mode.

Floor 1 perimeter tracks sum of wall lengths:  On the Room Data window, makes it so if you have a floor entered for Floor 1, whenever you change the dimensions of a wall, the Perimeter input for Floor 1 equals the sum of the lengths of all the walls in the room.

Auto copy Default Room Data to new rooms:  Makes it so whenever you create a new room, all of the Default Room Data window's inputs are automatically copied to the new room.

Show General Project Data window upon opening project:  Whenever you open a project or start a new one, the General Project Data window will open, if it is not already open.

Start a new project upon opening program:  Makes it so a new project is started whenever you open Rhvac.

Display values in decimal feet when using English units:  When checked, makes it so the dimensions on the Room Data and Default Room Data windows are displayed in decimal feet.  When unchecked and using English units, the dimensions are displayed in feet and inches.  Note that you can enter dimension data any way you want to regardless of this setting.

Automatically complete room names as you type:  Makes it so the room name is completed for you as you type if what you have typed so far matches one of the room names in the list.

Capitalize first letter as you type on General Project Data:  Capitalizes the first letter of each word you type in most inputs on the General Project Data window's Project, Client and Company tabs.

Automatically insert extended data when typing in a Favorite material:  When checked, copies any extra unseen data saved in your Favorites list for a material to the current material input on the Room Data window whenever you type in the material code rather than using the popup dialog.  For example, if you type in a glass material code into the Glass Material input rather than using the Glass Material dialog, if that material is in your Favorites list all of the data in the Glass Options area will be copied to the current glass, including the indoor shading device, insect screen, etc..  For floors and roofs, the extended data includes the floor covering and the roof material and color.  Note that this feature also works when typing in a material name on the Object Properties window of Drawing Board.

Show System Concept Warnings for systems with AED excursion:  When checked, makes it so a System Concept Warning pops up in the Evaluation of Projectwindow whenever a system has some amount of AED excursion.  Uncheck the box to globally turn these warnings off.

Warn when a system has no duct loads:  When checked, makes it so a warning appears in the Evaluation of Project window when you calculate loads for a system that has zero heating and cooling loads due to ductwork.  To enter the required data to let the program calculate such loads, click the Duct Load Factors input on the System Data window.

Exclude partitions from wall lengths for Floor 1 perimeter calc:  When checked, partition walls lengths are not included in the automatic calculation of the perimeter value that gets inserted into the Perimeter input of floor 1 (if the option to do that is turned on, as described earlier in this help topic for the Floor 1 perimeter tracks sum of wall lengths option).  When unchecked, partition lengths are included in the perimeter.  Regardless of this setting, you can always type any value you want into the Perimeter input.

Show Merge Notification at startup when needed:  When checked, if you have installed an update and selected not to overwrite the Equipment Picture Database during the setup, and that database was updated since your previous installation of Rhvac or Energy Audit, the Merge Notification dialog will open when you open the program.  Since the default setting of the setup is to overwrite the Equipment Picture Database this option is usually not important.

Show EER for air conditioners and air source heat pumps on reports:  When checked, the System Equipment Data and Room Load Summary reports will include the EER rating (if non-zero) for any standard air conditioner or air source heat pump equipment in your project.

Keep project file database compacted:  When checked, the project file database undergoes a repair and a compact operation whenever you save the project.  The same operation can be performed manually with the Repair and Compact Database feature.

Show non-glass U-values on Summary Loads reports:  When checked, the following reports will include the U-values in the descriptions of non-glass items:  Total Building Summary Loads, System Summary Loads, and Zone Summary Loads.

OK button:  Applies any changes you have made and closes this dialog.

Cancel button:  Closes this dialog without making any changes.

Apply button:  Applies any changes you have made to this dialog and leaves the dialog open.
