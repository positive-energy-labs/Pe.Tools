Drawing Last Saved in Previous Version

This dialog is shown by default when you first open a drawing that was last saved in Drawing Board for Rhvac Version 1 (the current version is 2).

 

Show this dialog when I open drawings done in previous version:  Uncheck this box to make it so this dialog will not open the next time you open a drawing that was last saved in Drawing Board for Rhvac Version 1 (the current version is 2).  If you uncheck this box you can reset this option by checking the appropriate box on the Drawing Board Options dialog.

 

Yes Button:  Closes this dialog, then searches through the fittings assigned to each elbow fitting on ducts on the drawing, and shows a realistic elbow for certain elbow fitting IDs.

 

No Button:  Closes this dialog, then sets each existing elbow fitting to be shown as simply a bend in the duct.
