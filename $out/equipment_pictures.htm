Equipment Pictures (System Data Window)

The Picture tab on the Equipment tab of the System Data window lets you see picture associated with the model number of the current equipment.  The image can be included on the System Equipment Data report if you check the "Include equipment pictures on System Equipment Data report" checkbox on the General tab of the Select Reports dialog.

Data and Picture Tabs:  Selects whether you want to view the selected equipment's specifications or its picture, if available.

Equipment Picture

Heating [or Cooling] Picture Filename:  Specifies the name of the picture file associated with the heating or cooling model number.  Click the button to the right of this input to open the Heating [or Cooling] Equipment Picture dialog, which lets you select a file to be associated with the model number you have entered.

Get Picture From Database:  Retrieves the picture associated with the current cooling or heating model number from the Equipment Picture Database.  This function is normally not needed if you selected the model number using the Find HVAC Equipment window, but if you entered the model number by hand, clicking this button will retrieve the picture associated with the entered model number.

Save Current Picture Selection To Database:  Saves the current picture file and model number to the Equipment Picture Database.  This function is needed only if you typed in the picture filename or model number rather than selecting them through the Find HVAC Equipment window  or Heating [or Cooling] Equipment Picture dialog.

View With Equipment Picture Database:  Opens the Equipment Picture Database window with the current model number and picture selected.

Fit Image In Container (Toggle):  Toggles between showing the picture at its original size or at a size that will just fit within the container.
