Export REScheck File (File Menu)

Icon: .  Keyboard Shortcut:  ALT, F, E, R

Opens the Create REScheck File dialog, where a file can be created for the REScheck program.  The file created will have an rck extension and can be opened by REScheck.  You may need to make further modifications to the REScheck project once you open it in that program.

REScheck Folder:  Specifies the folder name where the file will be created.

Browse:  Opens a Browse for Folder dialog, where you can change the folder where the file will be created.

Existing REScheck Files in Above Folder:  Lists any files with the extension 'rck" that are in the selected folder.

REScheck Filename to be Created:  Specifies the full path and filename for the file that will be created from the current project.

REScheck Code to Use for Above File:  Specifies the REScheck code that your local jurisdiction requires.

OK:  Creates the file and closes this dialog.

Cancel:  Closes this dialog without creating the file.
