Open Previous Version Project (File Menu)

Icon: .  Keyboard Shortcut:  ALT, F, J

Opens the "Open Previous Version Project" dialog, which lets you select an Rhvac version 6, 8 or 9 project file to convert to the version 10 format.  The original previous version project file will remain unchanged, and a new, converted version of the file will be created.  After selecting a previous version file Rhvac converts it to the version 10 format, and then prompts you for a filename to be used for the new version 10 file with the "Save Converted Previous Version Project As" dialog.

Notes:

·If the previous version project included a Drawing Board drawing, and that drawing was saved in an external DBP file rather than in the project file (which is not usually the case), you cannot save the Rhvac 10 project in the same folder and with the same base filename as the original project.  You must either modify the filename for the Rhvac 10 project or save it in a different folder.  The program will let you know if you need to do that.

·If an external DBP file was referenced by the previous version project, a new DBP file suitable for Rhvac 10 will be created as well.

·If the previous version project included a Drawing Board drawing, when you open the Drawing Board window the Catalog Browser will reference the catalog named, "Rhvac 10 Drawing Objects" rather than a previous version catalog.

·The new Rhvac 10 project cannot be opened in previous versions of Rhvac, nor can it be converted back to a previous version format.

·You can manually associate Rhvac version 6 and 8 project files (extension RHV) with Rhvac10.exe.  That will make it so when you double click on an RHV file it will open Rhvac version 10 and will perform the "Open Previous Version Project" function on that file automatically.  You will probably only want to manually create that association if you do not currently have Rhvac version 6 or 8 installed on your computer.
