Importing BPL Files (Bill of Materials Parts Database Window)

Bill of Materials Topics

To import parts or other records from a BPL (Bill of Materials Parts List) file, from the Bill of Materials Parts Database window click the menu "File | Import | Import BPL Files."  The Import Bill of Materials Database Lists dialog, shown below, will open.  This dialog will also open the first time you open the Project Bill of Materials window after you have installed an update that happened to include new parts that you might want to include in your database.  To create a BPL file, use the Export BPL File dialog.

Include checkboxes:  Check the box for each BPL file you want to import into your database.

Show older database list files that I have already  been notified about too:  This checkbox is only visible when this dialog is opened automatically after you have installed an update and new BPL files are available for import.  Checking the box makes it so you can see all of the BPL files in your "Importable Parts" folder.

Import:  Performs the import and closes this dialog.

Cancel:  Closes this dialog without making any changes.
