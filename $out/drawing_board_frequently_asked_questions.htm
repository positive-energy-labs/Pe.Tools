Answers

General

Q:  How do I get more drawing space?

A:  There are several things you can do.  One is to turn off the Catalog Browser by clicking the menu "View | Show Catalog Browser."  Another is to maximize both the main program window and the Drawing Board window (click the middle of the three buttons in the upper right hand corner of the window).  Another is to turn off the toolbars, which you can do by right clicking on the toolbar and unchecking the ones you want to turn off from the popup menu (all the functions of the toolbar will still be available in the program's menus and the right click popup menus).  Yet another way is to turn off the programs taskbar (click the menu "Tools | Taskbar | Visible").

Q:  How do I change the properties of several objects on the drawing at once?

A:  Hold down the Shift key and click all the objects you want to set the properties for, then click the menu "Format | Object Properties" and set the desired properties on the Object Properties window.  That will let you set the properties of all the objects that are selected.  Note that if you are wanting to set any of the properties on the Special tab, you must select only Smart Figure objects that have the same name.  For example, if you want to change the Material property for all the walls in a room, you must select only Wall objects.

Rhvac Drawing Objects, Chvac Drawing Objects

Q:  How do I handle multiple floors?

A:  Put each floor on a different Sheet.  To create a new Sheet, click the menu "Format | Sheets" and click the Add button on the Sheets tab of the Drawing Properties dialog.

Q:  How do I make my rooms take up less drawing space?

A:  Change the drawing to a smaller scale.  For example, if the drawing is currently set to 1/8" = 1'-0", change it to 1/16" = 1'-0".  To change the scale, click the menu "Format | Scale."

Q:  I started drawing my rooms in a bad location on the screen and now my house is growing off the borders.  How can I fix this without going through the work of moving every single room and other item one by one?

A:  Zoom out far enough to see the whole drawing, then select all the rooms on the drawing by clicking and dragging a rectangle around the entire floor plan.  Then click on a Room (or Zone) object and drag it to the new location.  But be sure to save the drawing first, in case you miss a wall or somthing and mess up that part of the floor plan.  That way, if you do mess up the floor plan, you can simply close the project without saving, reopen it and try again.

Q:  How do I make it so new rooms that I draw already have the wall, roof, etc. that I want?

A:  In Rhvac, open the Default Room Data window and enter the default materials that you want to use.  New rooms will then come in with the selections you want.

Ductsize Drawing Objects

Q:  How do I connect a duct system between two floors drawn on two different sheets?

A:  Drop a Supply (or Return) Trunk object on the drawing and resize it so that it has zero length so that it will represent a vertically running duct.  Manually set the Length property for that duct equal to the actual length of the duct.  Then position that duct where you want it and plug it in to an upstream on the same floor (on the same Sheet).  Finally, go to the sheet on the next floor and connect a duct to the zero length duct.

Q:  How do I draw a duct that goes straight up vertically?

A:  Resize the duct so that it has zero length and enter its Length property manually.  When you override the Length property of a duct, it retains that property until you resize or move that duct.  When you resize a duct, the Length property is again automatically calculated from the object's actual plan view
