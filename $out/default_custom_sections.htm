Default Custom Sections (Defaults for New Projects Dialog)

Bill of Materials Topics

To open this dialog, click the button beside the "Default Custom Sections" item in the Section Assignment group of the Defaults for New Projects dialog.

Add Row:  Adds a new row to the list.  You can then click on the new row and type in a section name.

Remove Row:  Removes the current row from the list.

Default Custom Section Names list:  Shows the names of sections that will be automatically added to new Bill of Materials projects.  You can edit the names by clicking on them and typing in a new name.

OK:  Accepts your changes and closes this dialog.

Cancel:  Closes this dialog without making any changes.
