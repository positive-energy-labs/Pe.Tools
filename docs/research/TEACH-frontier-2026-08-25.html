0. The one sentence

One canonical state per route (the route store). Chat plugin, sentence head, host wire, devtools panel and diagram are each a projection of declarations — never a second writable truth, never a claim the declaration did not carry.

Every thread below is one projection. Every doubt-0824 finding, read closely, is the same finding five times: a projection said something the declaration underneath it never said. Once you see that, the frontier stops being 40 owed lines and becomes one question per thread: where is the projection lying, and which declaration fixes it?

2a. Scope — one word, one writer, three readers

export type RouteWorkspaceScope = { kind: "thread"; threadId: string } | { kind: "workspace" };

/** Chat panes carry `thread`; route pages without it are explicitly standalone workspaces. */
export function resolveRouteWorkspaceScope(search?: string): RouteWorkspaceScope {
  const source = search ?? (typeof window === "undefined" ? "" : window.location.search);
  const threadId = new URLSearchParams(source).get("thread")?.trim();
  return threadId ? { kind: "thread", threadId } : { kind: "workspace" };
}

3. Targeting — the manifest is honest only where the store feeds it honestly

The manifest declares the feed vocabulary:

/**
 * Where a feed's options stand right now.
 *   live    — pushed (SSE); always current

4. Host / host-op — the same lie, one layer down

The host is the best-behaved thread and the model this page asks the web app to copy: C# op metadata is authority, 56 ops, codegen in sync, everything else a projection. Its frontier is small and concrete:

  • Two readers of "current session" disagree. host.json's sessionId is written once on attach and never invalidated; a host that outlives its session keeps advertising a reaped id while /call routes to the live bridge (host:72). A service file is a projection of the bridge that claimed to be truth. Fix: clear on reap, or stamp with a generation so a stale read is detectable.
  • Proof-lane cost. vp run @pe/host#test is 459 s, 453 s of it one Jet smoke (host:75). A metadata change pays a 7-minute toll; that is why host work feels slow.
  • /instances cannot pre-empt an id clash (the stem is minted host-side) and has no text-level proof path (SSR ships zero session strings) — host:76–77.
  • Specced, unbuilt: queue provenance (x-pe-origin, QueueLedger), GET /options/<domain> for editor completions, ?session= on settings schemas (host:78–79).
Nothing here blocks the web frontier. It is listed because "which session is current" is the root of every Liveness/basis claim the targeting head makes; if the host can lie about it, the head inherits the lie.

Read it as: the plugin reads only what a store declares; a store declares only what the host tells it honestly; a devtool shows only what the store declares, without touching it. The eight /family rulings are the cheapest gate on the longest chain. "Litigate only as needed" means a doubt line is spent by one of three things — a persisted ruling, a stamped proof, or a deletion — and two dry rounds on a thread end it.
