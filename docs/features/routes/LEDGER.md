# routes ledger

The route kernel and every web route's shared shape (ADR 0026, ADR 0027). Route-specific application lives in each route's ledger; design-language gaps live in the design-system ledger. Rebuilt 2026-11-02: the kernel and route-state lines of the design-system ledger moved here, and lines that ADR 0026, ADR 0027 or current code made stale were cut. Git holds the timeline. Terms: [GLOSSARY.md](GLOSSARY.md).

## Decided
- 2026-11-02, kaitpw, unification wave 2: one route asks one question about one kind of subject; stages are always pickable modes of that subject; Pea commits without a human under per-thread auto-approved consent. The full verdict list is ADR 0027.
- 2026-10-30, kaitpw, ADR 0026 verb kinds are three plus recovery: `workVerb` (patches), `commandVerb` (semantic command; review `none | shown`, `required` deleted by ADR 0027), `queryVerb` (host read outside the command catalog; a receipt without Work paths, never an undo barrier; may select Work), `recoveryVerb` (no patches, no command; `work.start-fresh` is a whole-Work barrier, offered only for a known older schema). A graph names the Page field that selects its Work (`workSubject`); selection order is Page field, then `?work=`, then the open document; one journal per selected key.
- 2026-10-30, kaitpw, laws fixed by the /families cutover: a verb's staleness basis is Work revision plus its `verbDepends` plus page epoch (`verbReadings` are the captures a verb starts and never count against it); `intent(scope, input, answers, ticket)` so an apply sends what its preview sealed; a query's patches write carries `expectedRevision(scope, result)`, default the revision the read started on; Stop sends a query's declared `cancel`; the owner derives carry-over patches on salvage; the Situation says the host's exact unreadable sentence beside the recovery review.
- 2026-10-29, kaitpw, laws fixed by the /ducts cutover: a URL field at rest is absent from the URL and `validateSearch` types only present keys; a control's review origin is place plus row plus subject, never args; a receipt-dirtied reading with mounted demand re-acquires, ports and verb captures never re-acquire by themselves; Target and Work resolution is kernel-owned (`useWorkScope`), so routes pass no scope or write ports.
- 2026-10-22, one shared address declaration and one Page owner prevent competing state: the route address projects URL and Pea field policy, and `createViewOwner` (`route/view-owner.ts`) owns Page changes. Named moves push history, gestures replace, and URL restore never replays actions. Routes with no graph own a Page through `useAddressPage(route)` and `routeFile(route)` (`route/address-page.ts`), so Back, Forward, history and Pea's lease work the same.
- 2026-10-22, Pea reaches a mounted Page through `route/view-bridge.ts` and `mcps/src/pea/capability-tools.ts`; `useRouteLease(route, page, { facts })` mounts the lease. A rendered lease acknowledgement proves accepted Page values only, never a refreshed Reading or a native effect. `?thread` names the lease relationship, not document authority. No lease, each on purpose: `/ops` (admin door; Pea runs ops through `pe_do`), `/bind` (binding is the person's press), `/pea` (the chat is where Pea reads its thread), `/parameter-links` (its only Page key is a fold; Pea edits the draft through verbs).
- 2026-10-21, kaitpw: Page is one route-owned reactive View model, not React state and not a second writable copy. URL and Pea projections derive from shared field definitions with separate access policies. Work stays host-owned; View transitions never replay native actions. The active route's Place owns the URL; browser workspace focus is local, thread tab memory is durable.
- 2026-10-23, a family's and a parameter's element ids change across document reload (PROVEN[browser + controlled dev session, copied Snowdon A/B UI apply and readback, `cc720203`, 2026-10-23]). Fresh plans and readbacks reacquire identity; evidence compares document lifetime plus family, type and parameter meaning, never element ids.
- 2026-09-15, Work uses revision admission. Semantic commands and durable receipts own external effects and recovery; Work does not duplicate that protocol, and operation status does not advance its revision. Optimism requires measured latency. `?work=` names Work; durable document Work uses the Address, not the openId.
- 2026-10-24, kaitpw: addressless Work survives document close, keyed by the original exact session and openId for inspection. A replacement lifetime cannot inherit it. Save As carries Work to the stable Address; closure removes native eligibility, never authored bytes.
- 2026-09-22, Readings are shared caches, including bound local files. Model freshness uses a per-document change mark, not elapsed time; focus does not replace a Reading under the person's hands. Disconnection is distinct from stale data. Target and subject changes revalidate, except Families (performance, 2026-09-26).
- 2026-09-22, measured cell edits stage values in the Reading document's display unit. Unit text stays as typed until commit; a read-only host parse supplies Revit's rendering, and a parse refusal stages nothing. Schedules, Family and Families share this cell contract.
- 2026-09-22, route, stage, pane and region scopes arbitrate keys by innermost live focus. Hidden panes are inactive. People choose stages; routes without stages declare panes directly.
- 2026-09-15, the head projects authoritative state: no fabricated counts or parallel policy. The SDK owns session and document identity and native receipts, Pe.Tools owns semantic commands, the browser projects them. [ADR 0009](../../adr/0009-one-atom-registry-per-app.md) governs the shared registry. Completed transcript cards keep their historical result, never the live route slice.
- 2026-09-15, seeds are read-only rendering inputs and cannot prove receipts. Acceptance needs real controls and durable outcomes.
- 2026-09-13, verbs live in one verb row (compact with page-state counts, expandable to a stack with reasons); an inline button elsewhere is the same verb with a narrower scope, and body layout never gates a verb. A refusal, a busy state and a done receipt are one flag that grows from the pressed thing and shifts nothing; no toasts. A busy flag's stop cancels the wait only (`/call` has no cancel lane).
- 2026-09-13, staged Work is a band whose frame the Situation owns and whose body the route fills. One page log at the bottom of a route holds every route event and opens receipts. Silence means fine.
- 2026-09-14, a verb's input comes from `Ctx`, never a store wrapper; pure projections a graph needs live in the graph. A file ladder is a sentence slot; a parse error marks the slot caution.
- 2026-09-15, Chat's send is a Situation verb, not a button of its own (kaitpw: "it uses primitives the way i want, keep it that way"); its look is not liked. Threads and World are view modes of Chat, not stages.
- 2026-09-12, a route needs no Revit unless an operation does; each operation gates its own requirements. Show only what helps the current goal.

- 2026-11-02, kaitpw: the wave-2 noun list is frozen as ADR 0028 (seven nouns; Pea and the web are two clients of one catalog). Pods as route authors is the point ("especially 34, cant emphasize that enough").
- 2026-11-02, kaitpw (provisional, "not sure if i resonate but seems reasonable"): a geometry read over a whole family document counts as bounded (scope kind for family documents only); project-document geometry reads must be narrower than the document. Revisit if the scope guard shows a better axis.

## Tried & rejected
- 2026-11-01, a stage per subject inside one route (spike A, `t3/kernel-stage-subject` @ 6010929e, `StageDecl.subject`): it fixed the wrong picker and the URL leak, but it grew the kernel to serve one route's two products and dropped the other stage's subject on a switch. Replaced by the route split (ADR 0027 rule 1).
- 2026-11-01, keeping readings alive by keeping every source: hiding a tab released readings through React `Activity` (red test `shell/readings-retention.test.tsx`, spike B), but holding every source would keep workers, ports and GPU resources. Retention must be decided per reading kind.
- 2026-10-22, generating route addresses from C# (no consumer for the crossing), and dropping the address package for TanStack `validateSearch` alone (Pea reads and sets fields host-side, without the web app).
- 2026-10-22, writing the renderer-derived Ducts pose into Page superseded the accepted Pea snapshot before its render acknowledgement. Keep the resolved fit in renderer observations; do not weaken receipt freshness for a second Page write.
- 2026-09-23, route-head shapes from the families demiurge: S5 no head (sentence only) killed because scan speed dies (house law 3); S2 page log as the ledger rejected because chronology is not state; S3 table-is-the-page kept only as a candidate because host-level diagnostics need one unplaced slot.
- 2026-09-15, a universal mutable route object or one route-wide lifecycle: it hides the difference between authored Work, observed Readings, Page navigation and external outcomes. Compose owners instead.
- 2026-09-13, Situation variants that lost: the key/value ledger as the head, an always-visible breadcrumb rail, stage as tabs over the verb gutter, refusal as a line under the verb row or as the verb's label, staged Work in a right margin, and `WorkingHead` (three registers stacked, GUID labels: "horrendous").
- 2026-09-09, the claim that document keys and receipts alone prevent every stale read or duplicate mutation: keys separate open lifetimes; Effect refresh orders reads within one lifetime; host admission and request identity govern retries.
