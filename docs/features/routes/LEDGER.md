# routes ledger

The route kernel and every web route's shared shape (ADR 0026, ADR 0027). Route-specific application lives in each route's ledger; design-language gaps live in the design-system ledger. Rebuilt 2026-11-02: the kernel and route-state lines of the design-system ledger moved here, and lines that ADR 0026, ADR 0027 or current code made stale were cut. Git holds the timeline. Terms: [GLOSSARY.md](GLOSSARY.md).

## Decided
- 2026-11-03, Work binds by the canonical Address key `{binding: address, target}` whenever an Address exists; a cold closed target shows its retained Work read-only. A binding to the live open ref is an integrity defect (FANS P02/P04, drive-9 defect K). One fix unit IDFIX owns the seam; CL writes only the host/mcps law. (controller, kaitpw away)
- 2026-11-03, controller, kaitpw away: D4 blocks the /fans cutover. Read-only (closed-document) Work must refuse every writer (edit, Revert, undo/redo, recovery confirm) through one writable-authority check; a write that can reach a closed document's Work is a data-integrity hole, and integrity seams are never shipped around.
- 2026-11-03, browser mount lifetimes (orchestrator and counsel, from `.artifacts/tmp/mount-parity/REVIEW.md`): the admitted mount lives on three lifetimes. Application: a refcounted registry keyed by canonical WorkKey (owner, presenter and composer share an entry; last release drops it) holds the Work journal and Timeline projection, rebuilt from the host feed `ready.history{acks, from}` and the `receipts(scope)` feed on the same WorkJournalDoor; the browser never derives a receipt from a submission result. Place: Page, address/tab memory and retained accepted readings. Visible pane/attempt: subscriptions, workers, GPU and focus; hide releases these and never erases Page, history or accepted values. Readings invalidate only from host evidence (receipt `dirties`/effects, the `/pe/reads/resolve` freshness generation), never from command input. Parity is a closed `BrowserMountCapabilities` census plus ordering laws as unit tests, and user journeys as pe-browser scenarios, each checked by removing one connection.
- 2026-11-03, closure authority (orchestrator and counsel): for a builtin, runtime admission recomputes the hash of the committed `source-closure.generated.json` envelope, so `BuiltinEnrollmentFailed` at startup detects a tampered or inconsistent envelope, NOT source drift; source freshness belongs to the producer gate (`route-graphs.ts --builtin-closure-only --check` in build/verify, plus dev regeneration), because an installed host has no sources to read (8c3c36c9, 44c8369c).

- 2026-10-22, writing the renderer-derived Ducts pose into Page superseded the accepted Pea snapshot before its render acknowledgement. Keep the resolved fit in renderer observations; do not weaken receipt freshness for a second Page write.

- 2026-09-15, a universal mutable route object or one route-wide lifecycle: it hides the difference between authored Work, observed Readings, Page navigation and external outcomes. Compose owners instead.
- 2026-09-13, Situation variants that lost: the key/value ledger as the head, an always-visible breadcrumb rail, stage as tabs over the verb gutter, refusal as a line under the verb row or as the verb's label, staged Work in a right margin, and `WorkingHead` (three registers stacked, GUID labels: "horrendous").
- 2026-09-09, the claim that document keys and receipts alone prevent every stale read or duplicate mutation: keys separate open lifetimes; Effect refresh orders reads within one lifetime; host admission and request identity govern retries.
