The factory

One process measures every commit on main, spends tokens only on findings above a bar, and asks you through a pull request. It stores nothing that git or a recompute cannot give back.

01The loop

Judgment lives in two places: inside the actuator, and at the pull request. Everything else is deterministic code.

The feedback path is not a second mechanism. A squashed pull request moves main, main moving is the trigger, and the trigger runs the sensors.

03The system

Two channels share everything between machines: origin for what is durable, HTTP for what is live.

The running factory is never the code it mutates. The daemon runs from its own clone; sensors and actuators run in a clean worktree of the measured sha.

04Declaration

One typed file. Adding a capability is adding an object.

// factory.config.ts · the whole factory
export default {
  ref: "origin/main",
  port: 4747,
  sensors: { loc, hotspots },              // (sha) => Finding[] · {mechanism, path, evidence}
  loops: [
    { name: "format", on: "merge", act: fmt, gate: "auto" },
    { name: "purge",
      on: { churn: 500 },                  // lines changed since this loop last ran
      sense: "hotspots",
      when: f => f.evidence.churn > 200 && f.evidence.shims > 0,   // the bar
      act: purge,                          // claude -p /purge <path>, env scrubbed of API keys
      budget: { perDay: 1 },
      gate: "pr" },
  ],
} satisfies Factory

Not declared: retries (the next trigger retries by construction), branch and worktree names (derived from loop and sha), prompt text (a prompt is a skill call).

05Laws

Store only what cannot be recomputed.

Readings and findings are a cache. Proposals are branches. Verdicts are pull request outcomes. Losing the daemon box loses nothing.

cache.jsonl · origin
No model in the tick.

Triggers, bars, budgets, and dispatch are code. Your quota buys diffs, not orchestration.

src/main.ts imports nothing that talks to a model
A sensor is a pure function of the sha, and it does not judge.

It returns evidence. The loop holds the bar in when.

(sha) => Finding[]
Counts are gauges, never gates.

A gate fails for the behavior you want to prevent, not for a number that is easy to move.

no setpoint · no error term
Act only above the bar.

Under the bar a finding is listed and costs nothing. Over it, one actuator run within budget.

when · budget.perDay
Identity is derived, never minted.

Runs, branches, and worktrees are named by loop and sha. Two machines compute the same name.

factory/loop/sha7
Agents propose; you approve.

Deterministic actuators may gate themselves. Anything with a model inside waits at a pull request.

gate: "auto" | "pr"
Subscriptions only, by subprocess.

Every spawned agent has API key variables removed from its environment, so billing lands on the subscription.

unset ANTHROPIC_API_KEY · ANTHROPIC_AUTH_TOKEN · OPENAI_API_KEY
Cross-review is directional.

Codex drafts, Claude reviews. The inverted pair measured worse than no review.

One ref, squashed.

Every branch lands on main as one commit with a written message. Packages touched per merge is a reading.

07Why not the others

shapeepitaph
SQLite event log, git notes, orphan log branchThree answers to sharing data that is re-derivable. Notes do not fetch by default. The HTTP page already shares the live view.
own verdict buttonsOpen-in-IDE runs on the daemon box and breaks from the laptop. Proposals must reach origin anyway, and a pull request has the buttons.
factory.tomlNeeds a parser, path templating, and an expression evaluator for the bar. A typed object needs none.
setpoints and an error termThe sensor PoCs killed count gates. The sensors worth having are predicates.
dev, distill, release branchAll solve unreadable history. Squash to main solves it with one ref.
owed as a logMachine findings re-derive. Human owed lines are dated bullets, and their log is git log -p.
Temporal, Mastra, platform pileEach adds a state owner to buy waiting that a pull request already does. The Mastra agent layer needs API keys.
