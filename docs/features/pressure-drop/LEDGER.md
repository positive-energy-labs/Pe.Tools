# pressure-drop ledger

The surface that makes a firm model compute duct pressure drop: `/ducts` view `losses`, grille-first, where a fitting's loss is set by its type's ASHRAE table, Pe computes the critical path and fan static, and the values are written into Revit so they travel with the model. Campaign evidence (a client model under NDA) stays gitignored in the main checkout's `.artifacts/pdrop/RECORD.md`; prototypes in `.artifacts/pdrop/protoui/`. Rebuilt 2026-10-04 after the closing drive.
