# Pressure-drop ledger

The surface that makes a firm model compute duct pressure drop: a grille-first drawer where fitting losses are set by type rule, Pe computes the critical path and fan static pressure, and values are written into Revit so they travel with the model. Campaign evidence (a real client model, NDA) stays gitignored under `.artifacts/pdrop/` and `.artifacts/runs/`; the 2026-10-14 Codex run is mined into `.artifacts/runs/pdrop-muse/` (main checkout).

Family TYPE `Pe_Catalog` names a table; staged Work `catalogs[JSON.stringify([family,type])]` overrides it and remains local after apply. Superseded 2026-10-05 (`WHY-NOT-REVIT.md` reason 3): the ASHRAE method computes once a fitting stores a table; fittings start empty (183 of 4,571 store a table on a fresh open; an earlier copy read 388, unexplained), Revit's own pick is the first applicable table in text order (CD3-11 on 221 round elbows), and an elbow's angle comes from the two ducts drawn into it, so the 87 of 1,235 round elbows with a duct a hair off its direction (about 7%) can never hold one; plan rotation is not the cause (control panel `Pages/pdrop-tour`, `offaxis.csx`).
