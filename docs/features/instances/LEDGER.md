# instances ledger

## Decided
- 2026-08-16 — Instances state is a **row-level pipeline verdict** (world phase), not a value pseudo-dimension: the fleet is the first real consumer of the `verdict:` column clause (R5), and essentially nothing here maps to the four value axes. That is the census's result, not a gap.
- 2026-08-16 — `live` wears the `done` tone as a deliberate stretch ("the bridge connection landed"): the meaning band has no running/connected role and `ink` under-states it against `booting`. Recorded so the next fleet-ish surface (ops?) doesn't invent a different answer. Do not mint a hue.
- 2026-08-16 — A lifecycle cockpit is legitimately blue-dense: every verb here (declare ×3, restart/stop per row, start-again per killed row) boots or kills an OS process, so all wear `commit` per the letter of the scarcity law. The `VerbGroup` radius line carries the blast statement once.
- 2026-08-16 — Killed worlds and "yours — not managed here" render italic + `--r-ink-mute` at whole-row scale, borrowing the dropped/locked cell-and-outcome law; replaced `opacity-[0.55]`, which the language rules nothing about.
- 2026-08-16 — Honest empties beat "—": "no open document" (live world, none open) and "nothing observed" (registry-only world) say which silence it is.
- 2026-08-16 — The seen/started age is a number, not a verdict: freshness has no subject or threshold, so it can never rank fresh-vs-stale or become queue work. Rendered mono secondary ink, no colour, no squiggle.

## Tried & rejected
- 2026-08-16 — `PHASE_COLOR` in `host/fleet.ts` (`--pe-blue` live, `--cat-kiln` booting, `--cat-clay` unresponsive, `--muted-foreground` dead): taxonomy and commit hues carrying state. Deleted; phase→tone mapping belongs to the rendering route as `phaseVerdict`, and fleet keeps no colour opinion.
- 2026-08-16 — Route-local `Btn` atom and dashed declare-button borders: the dashes meant "button", not seam.

## Owed
- Bless `done` as also meaning "healthy/connected" in the verdict-tone vocabulary (one sentence in `master-table/model.ts` or `design-lang.css`), or rule that connectivity is what `ink` + the word carry.
- Rule the row-scale idiom: bless italic + `ink-mute` as the row-scale reading of the dropped/locked law, or give `verdict:` a `dim` treatment that owns it (`Verdict.dim` exists, spent on the dot).
- The ledger rail is an outcomes lane the language cannot build: `OutcomeLine` carries no actor, time, or target ("outcomes are orphans"), so the timestamped attributed lines stay hand-rolled until the state model grows outcome links (design-lang ledger, Owed).
- For joint review only if blue-density is re-litigated: a bordered-commit rank for row-scale writes. Skepticism of growth says no.
