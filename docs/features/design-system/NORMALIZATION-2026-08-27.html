The shape we adopted

current implementation, not a future promise

Proven now

The app is unprefixed Tailwind. styles.css is the entry/import order. design-lang.css owns canonical --r-* tokens, live shadcn projections, semantic @theme inline colors, non-inline PE font tokens, dark handling, and existing type/face/case utilities.

design-defaults.css owns only opt-in semantic HTML defaults and page-wrap, scoped through [data-pe]. The app root carries data-pe. Animations and behaviors remain explicit utilities or components, never global defaults.

Reserved boundary

The pe: prefix is reserved for an independently compiled portable CSS/component boundary. It does not prefix current app routes or locally sourced components. Portable output will omit app-owned Preflight and can curate its own bundle.

That portable bundle is recommended next work, not current proof. It needs isolated-HTML, computed-style, accessibility, visual hierarchy, density, and single-file byte evidence before promotion.

Falsifiers that made the receipt honest

each lesson changed custody or arithmetic

  1. First token and template traversal. Source-text quotes and braces hid the first utility; template heads, spans, and nested substitutions had to be collected exactly once. The route measurement moved through 308 → 346 → 348 before normalization.
  2. Mounted-route custody. The route ratchet reads imports from routeTree.gen.ts, scans only those ./routes/* sources, and excludes explicit prototype routes. An unmounted route-shaped file cannot move the count.
  3. CSS prototype blindness. CSS topology uses a separate all-CSS collector that sees directories beginning with proto; only TS/TSX normalization debt keeps prototype exclusions.
  4. Directive remainder. Exact ordered equality is paired with removal of comments and matched directive spans; declarations and unknown directives left in styles.css fail.
  5. Formatting is a real gate. The standard unqualified web check—not a no-format substitute—required canonical formatter output on the nine named route files.
  6. Font indirection. PE font definitions moved together into non-inline @theme so font-pe-* utilities retain custom-property references; values and taxonomy did not change.
  7. Syntax-complete deprecated spelling rule. The source-wide production-literal hard zero catches typed and untyped arbitrary forms, variable shorthand, variants, directional modifiers, and important markers. Quoted deprecated utilities intentionally fail: examples must teach the canonical vocabulary. Bare variables, inline style values, custom-property plumbing, veil expressions and unrelated arbitrary utilities remain excluded.
  8. Generated route-tree custody. Web proof may regenerate route-tree noise. The receipt names its byte count and SHA-256; only generated noise was restored, and the final tracked tree is clean.
  9. Metric arithmetic. The 285 route substitutions were not naively subtracted from 348: 12 sat outside the old narrower guard custody, so the honest intermediate baseline was 348 → 75. The exact 18 spacing projections then produce 75 → 57.
