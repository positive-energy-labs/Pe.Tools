The supported shape

proven now versus reserved later

Proven now

base.css is one flat browser-native entry: raw light/dark --r-* and --viz-* tokens, native shadcn projections, marker-owned color-scheme, and scoped semantic defaults plus page-wrap. The isolated probe and remote-factory.html are one-link consumers; this report embeds the exact same bytes in <style id="pe-base">. The source is checked in and guarded; it does not auto-update.

App authoring

styles.css owns import order. design-lang.css owns @custom-variant, @theme/@theme inline, semantic Tailwind vocabulary, and type/face/case utilities. The app remains unprefixed. Non-inline PE font tokens preserve custom-property indirection. Global Preflight remains app-owned.

Reserved boundary

pe: is reserved only for a future independently compiled portable utility/component bundle. That work is not implied by this receipt. A portable artifact would omit app-owned Preflight and must earn isolated HTML, computed-style, accessibility, visual hierarchy, density, and portability proof.

Negative boundary

The public base is tokens, scoped semantic element defaults, and page-wrap only. Components, animations, interactions, and behavior stay out; app components remain app-owned. Explicit semantic utilities/components own any future animation or behavior.

Falsifiers that changed the mechanism

each is now a direct lesson or invariant

First token and template traversal

Source-text quote/brace scanning hid the first utility. Literal heads, template spans, and nested substitutions must be visited exactly once. The regression is executable.

Mounted-route custody

The route census parses routeTree.gen.ts imports and scans only mounted ./routes/* sources, excluding explicit *-proto routes. An unmounted route-shaped file cannot affect the metric.

CSS proto blindness

CSS collection sees below directories beginning with proto; only real generated/dependency/artifact roots are skipped. TS/TSX prototype exclusions remain narrower and intentional.

Directive remainder

The six styles.css directives are ordered exactly, then comments and matched spans are removed; any declaration or unknown directive remains and fails.

Formatting is a real gate

The unqualified web check—not a no-format substitute—required canonical formatter output on the named route files. Formatting output is retained when it is the canonical result.

Font indirection

PE font definitions stay together in non-inline @theme, preserving custom-property references in emitted font-pe-* utilities without changing values or taxonomy.

Syntax-complete spelling policy

The source-wide token-level matcher covers the repaired matrix: typed/untyped and shorthand arbitrary values, important modifiers, directional families, variants, radius, PE fonts, and quoted/parenthesized prose. It is not a claim to implement all Tailwind grammar; deprecated spellings in examples intentionally fail.

Generated custody and arithmetic

Sanctioned web commands may rewrite the generated route tree; proof restores only that noise and checks bytes/hash. The 19-versus-18 spacing discrepancy is scanner arithmetic, not a hidden extra design win; the honest guarded frontier remains 57. The base boundary checks selector-to-property ownership and rejects CSS identifier escapes, so allowed selectors cannot grow component skins.
