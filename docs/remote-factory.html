Why REACH has three shapes

Both tunnels work because the NATed machine dials outward — outbound is always allowed, so neither needs port-forwarding. Everything differs after the handshake.

Glossary

NAT — private addressing; why nothing outside can dial in.
Tailscale — private WireGuard mesh; your devices only, direct after handshake.
MagicDNS — tailnet hostnames. beast:5173 just works.
DERP — Tailscale's relay when hole-punching fails. Carries ciphertext.
Serve / Funnel — a real TLS cert on a tailnet port / publish it publicly.
ngrok — public tunnel to one port, relaying every byte forever.
VPS — rented Linux with a public IP. A computer, not access.
Subnet router — a tailnet node routing to non-Tailscale devices. Dies with its host.
Console session — the real logged-in desktop on the real GPU.
RDP — takes the console session over. Unsupported for Revit.
Sunshine / Moonlight — host / client. Streams the console session, survives disconnect.
KVM over IP — HDMI in, USB keyboard out. Pixels from below Windows.
EDID — the monitor identity the KVM presents so Windows draws something.
Virtual media — KVM emulating a USB drive. Remote OS reinstall.
GLKVM Cloud — GL.iNet's relay for the Comet. Free, on by default, disableable.
ATX board — wires a KVM to a desktop front-panel header. Towers only.
Fingerbot — a robot that presses the power button. The only CUT on a laptop.
Wake-on-LAN — a magic packet wakes a machine. Needs a sender on the LAN.
Fast Startup — Windows' hybrid shutdown. Silently disarms WoL.
Modern Standby — S0ix. Looks on, network throttled, then hibernates.
S5 — a real power-off. What WoL has to wake from.
DialogBoxShowing — Revit API event. Auto-answer modals instead of viewing them.
