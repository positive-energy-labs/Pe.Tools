## Context

The host uses Effect as a library for the bridge, not as the standard library. At c510da4b: 3 `Context.Service` declarations, 0 `Effect.fn`, 71 `Effect.run*` calls of which 4 are at a process edge and 60 are inside the host between Promise code. Each mid-program `runPromise` ends the fiber: the scope closes, interruption stops, services are re-provided per call (`NodeServices.layer` rebuilt at 16 sites), and a typed failure becomes a thrown `Error` whose only identity is its message (`bridge.ts:622` picks cancelled or failed by regex). Lifetimes are ambient: `ActionJournal` and `HostLog` are module `let` singletons, `RunConsents` runs the ADR 0027 consent window on `setTimeout` against `Date.now`, harness children die by `taskkill /T`, and `Date.now` is read at 240 sites. kaitpw does not trust any cancellation the product attempts today, and cannot try undo of Pea writes or a different permission model across threads and tabs, because no owner of lifetime exists.

Effect at the edges only (a decoded frame, a typed bridge client) is better than none. Effect in the middle, with Promises on both sides, is worse than none: every boundary pays the cost of both worlds. The cost is per boundary, so the number of fiber ends, not the fraction of Effect code, is what makes adoption all-or-nothing.

## Decision

1. **Effect is the standard library for the host, the MCP server and the web's doors.** Processes, files, paths, HTTP, config, schema, time, collections, tracing and testing come from Effect modules. Hand-rolled code where a module exists is a finding.
2. **One fiber per request.** A request, a tool call, a bridge frame, a harness event enters a fiber at the edge and stays on it until it answers. Every spelling of the run family (`Effect.runPromise`, `runSync`, `runFork`, `runPromiseExit`, `runCallback`, the `*With` forms, `runMain`, aliases, destructures and computed access) is legal only on a line that carries `// effect-edge: <reason>`, and the `pe/effect-edge` lint refuses every other site. The reason comes from a closed vocabulary: `process-main`, `als-crossing` (retires in phase 5), `cli-main`, `test-runner`, or `island, phase 5`. An island is a per-file count in `ts/tests/repo-guards/src/effect-islands.baseline.json`, and that baseline only shrinks. The guard compares it to the merge base, not HEAD. The post-phase-5 island threshold is zero. The "four edges at c510da4b" (`host-program.ts`, `app.ts`, `request-identity.ts`, `packages/browser/src/keeper.ts`) were an inventory, not a whitelist; two of them were fake edges and phase 3a deleted them. Request identity is a required immutable `Context.Service`, provided once at admission with `Effect.provideService`. This replaces the `AsyncLocalStorage` crossing in phase 5. Effect 4.0.2 has no `FiberRef` module. Forked durable work captures causal identity and journal ownership explicitly. It never inherits a request cancellation lifetime.
3. **Dependencies are services.** Anything with a lifetime is a `Context.Service` built by a scoped `Layer` and provided once in `hostProgram`: `RevitBridge`, `ActionJournal`, `HostLog`, `RunConsents`, `HarnessThreads` with its spawner, `MachineOwner`, `CaptureStore`, `ReceiptExport`. Module-level `let` state standing in for a service is a finding. A test swaps a layer, never a module.
4. **Nothing ambient.** Time comes from `Clock`, children from `effect/process`, files that need a scope from `FileSystem`. `TestClock` proves ADR 0027's consent window. Persisted timestamps (the `at:` on every event and decision) come from `Clock` through `DateTime`. Exceptions, recorded here because Effect falls short: `node:os` for `homedir` and `hostname`; native realpath for worktree identity (Effect's `stat` has no `ino` above 2^53 and `realPath` keeps 8.3 names).
5. **Failures are values.** Expected failures are `Schema.TaggedError` in the type (`Refused`, `CommandRejected`, `StepFailure`, `BridgeError`, `NoRevitSession`, `Cancelled`); one `HttpRouter.middleware` maps the typed failure union to HTTP with `Effect.catchTags`. The host already uses `effect/http` HttpRouter (`call-route.ts:57`, `pe-routes.ts:27`, `app.ts:307/323` at 03964beb). Phase 5 deletes the Web-handler island inside it: the re-match at `pe-routes.ts:363-369`, `fromWebHandler` at `:1455`, and response normalization at `:1462-1473`. It also deletes the per-route catch and `toProblem` at `call-route.ts:541-561` and `:1291-1371`, including message-prefix classification. The `/call` operation-key dispatch stays a generated table from operation metadata. It never becomes a switch arm per operation. A `throw` inside an Effect, and a regex on an error message, are findings. `Cause.pretty` inside an error message and text classification of a response (`classifyEndpointFailure`) are findings that phase 5 deletes. Plain `_tag` classes are allowed only until the file they live in is converted.
6. **Spans are diagnostics.** A reusable effectful function uses `Effect.fn("name")`. `Effect.fnUntraced` is no longer the house idiom. Spans replace transcript scans and hand timing records only. The domain owner produces durable facts such as consent persisted, native committed and delivery survived host death. Receipt export never infers these facts from a trace. It retains native receipt ingestion and journal evidence.

    Adopt the direction advocate's section 8 installed sink: a local completed-span ring exposed through an authenticated diagnostics read route, plus rotating NDJSON files. The ring holds at most 2,048 redacted summaries of at most 2 KiB each, for a 4 MiB payload bound. The writer queue holds at most 256 summaries at the same item bound, for a 512 KiB payload bound. Four files of at most 8 MiB bound disk payload at 32 MiB. Overflow drops the oldest telemetry and increments a monotonic drop counter. One scoped writer drains the queue. Its configuration names a finite shutdown flush deadline. These bounds exclude runtime object overhead. The sink copies flat summaries and discards span and Exit references. ReceiptExport consumes only allowlisted completed spans. IDs and causal links connect diagnostics to durable facts. Attributes exclude model blobs and secrets. Active span residency is bounded by request, worker and child limits. A lagging state subscriber receives a gap and replays the durable cursor instead of silently losing state events.

7. **The edge is a Schema.** Every boundary the host does not author is decoded, never cast: the thread store (`events.jsonl`), harness child config and probe responses, CLI discovery, the web's harness SSE frames and tab memory, MCP takeoff blobs. Effect Schema owns these. Persisted records carry an explicit version. Decoded history passes through one domain reducer that rejects impossible transitions and marks damaged history. Authority recovery fails closed or reads the authoritative record. Browser history may degrade with a gap. Transport metadata is inside the decode boundary: the SSE `lastEventId` is decoded with its frame, and the resume cursor moves only after the frame is accepted. The `fromStandardSchema` bridge (zod under Effect) is deleted in phase 8; until then its import count only shrinks, and a new edge uses native Effect Schema. Unconverted kernel consumers retain zod until their schema slice in rule 8.
8. **Convert handler schemas with handlers; retain a residual kernel wave.** MCP SDK v2 (`@modelcontextprotocol/server` 2.4.0, landed c510da4b) takes Standard JSON Schema, and Effect 4.0.2 emits it through `Schema.toStandardJSONSchemaV1(Schema.toStandardSchemaV1(S))` (PROVEN[compile, 2026-11-02]). Handler inputs, responses and errors move to native Effect Schema in the same pass as each phase-5 conversion. The dependent catalog and Pea projections follow their authoritative contracts in that slice. The residual zod kernel moves to Effect Schema in phase 8, with two known deltas to rule on: Effect's JSON Schema for numbers and optionals is wider than zod's, and `additionalProperties` differs between beta.92 and 4.0.2.
9. **Where Effect does not fit, and why.** `ducts-domain` is pure values in, values out; wrapping it adds nothing. React render code stays React with `effect/reactivity` Atom; `Effect.gen` in a component is a finding. `eventlog`, `workflow`, `cluster`, `KeyValueStore` and `TxRef` are rejected as a second owner of state beside the journal. `Schedule` owns in-process backoff only (machine poll); the journal owns retry across restarts because receipts must survive one. `Path` is adopted where a scope is needed, not for every `join`.
10. **Every route declares one of three lifetimes.** A route receives no raw launch capability; its shape decides who owns the work.

    - *Request-owned read*: the work lives on the request fiber. The fiber dies, the work dies.
    - *Durable command*: ownership transfers to the journal at submission. The response can return before the work ends, and losing the client does not stop the work.
    - *Subscription*: the route observes. Losing the observer never stops the turn.

    A native Revit read is a durable dispatch owned by the bridge scope and joined by request fibers through one `NativeReads` service. Its identity is a typed resolved read descriptor: operation, process incarnation, open-document lifetime, schema-encoded input with sorted keys, and required freshness generation. Canonical input alone is not an identity. Admission resolves implicit targets before joining. Each caller passes admission before sharing. Per-caller attribution stays outside the shared result. A fresh-after-write caller never attaches to a pre-write flight. The browser has no second definition of read identity.

    Joiners are refcounted. When the last joiner leaves interrupted, `NativeReads` requests cancellation and marks the dispatch retiring. A new join during retirement receives a typed retryable refusal. It never joins a doomed dispatch or starts a duplicate behind it. One native dispatch identity persists until terminal settlement. Only then does the service forget the entry. Real typed refusals reach every joiner. Initial caps are 64 entries and 256 joiners per entry, subject to tuning. Encoded keys and results also have configured byte bounds under rule 15. This service joins in-flight reads; it does not cache successful values. A receipt names one cancellation outcome: `never-dispatched`, `native-cancel-requested`, `native-acknowledged`, `committed`, or `unknown-until-reconciled`. A cancelled request fiber is never reported as a cancelled Revit write.
11. **The serial slot survives transport replacement.** A session actor keyed by process incarnation owns one native dispatch at a time. Its bounded queue uses FIFO order without priority or preemption. Excess work receives a typed refusal. A scoped worker alone advances queued, dispatched and terminal state. Interrupting a waiter removes only that waiter. It never releases a successor. `op.cancel` bypasses the worker permit and work queue.

    Dispatch is fenced by process incarnation plus connection epoch. The actor survives a replacement connection to the same process. Uncertain connection loss enters reconciliation. The actor releases its slot only on native idle or terminal evidence, or process death as a distinct terminal fence. A timer never releases it. Cancel accepted is not proof that the native operation stopped. A non-cooperative operation remains unavailable or unknown until evidence settles it. Browser abort signals are not assumed to arrive at Node (geometry-perf thread, 2026-10-31). Rule 10 supplies the join lifetime.

12. **Supervision.** Every forked fiber (consent window, poll, probe, dispatch) is forked into a service's scope with `Effect.forkScoped` or `Effect.forkIn`. A detached `runFork` is a finding. A settlement operation (consent, queue release) is one typed operation: a persist failure or a listener failure cannot strand a waiter, and cleanup settles every waiter.
13. **Tests serve invariants, not coverage.** kaitpw, 2026-11-02: "pls do not treat tests like something crucial to keep ... might prefer if we ended with less coverage and less tests ... move to pe-browser tests more ... i HATE units". Restated: unit tests are not a preservation target. When a module converts, its Promise tests are deleted, not ported. A deterministic test stays only when it guards a consequential invariant that the browser lane cannot falsify: the consent window on `TestClock`; settlement fault injection; A/B/C queue interruption, including "cancel passes the permit"; runner teardown; native-read sharing (`native-read-sharing.test.ts`, `slow-capture.test.tsx`) until the pe-browser gate of the geometry-perf thread is green. pe-browser is the target lane. The 70 test islands go with their tests. `ts/apps/host/tests/effect-test.ts` keeps its top half only while surviving invariant tests need it. Its Promise-fixture half is deleted with those fixtures. Do not grow a house test framework.

14. **Causal ownership crosses processes as data.** Every admitted operation carries a host-validated owner capability, causal parent id, cancellation policy and terminal state. Submission establishes this ownership durably before acknowledging acceptance. Stop addresses the owner and its defined descendants. The protocol defines the command set a turn Stop cancels, the fate of admitted child commands on parent failure, and the condition for settling a parent. A parent cannot claim settlement while its policy still requires unresolved descendants to settle. Routes receive separate submit, join, observe and stop capabilities. Neither a Context nor a fiber-local value crosses processes. The protocol carries explicit data, not ambient request state.

    Acceptance uses a real turn through MCP to a host write with two tabs observing. Close one tab, kill the MCP caller, then Stop the root. Correlate the causal ids and read each native terminal outcome. An observer disconnect must not masquerade as owner Stop.
15. **Scoped services retain bounded state.** A scoped service may not retain unbounded completed history. Active runs stay in memory. Terminal authority and recovery records live in indexed durable storage with cursor reads. Retire active projections after their dependents settle. Recovery queries the durable owner. Unknown old invocations refuse closed instead of reopening authority. Every cache, queue and subscriber list names an entry bound, a byte bound, and an eviction or overload result. Service configuration owns these bounds. HTTP admission, SSE subscribers, SDK caches, native queues and active thread event windows obey the same rule. The segment/byte retention in `ts/apps/host/src/host-log.ts:17` is the model.

    The memory claim is UNPROVEN until the perf thread's falsifier passes. Through real browser/MCP doors, run equal batches of short turns after warm-up. Settle commands and close children and tabs between batches without deleting history. Record private bytes, retained heap, active fibers/children/subscribers, and retained transcript/run/answer counts at quiescence. Keep trace export configured as shipped. Restart against the accumulated store to distinguish replay residency from orphan work. Acceptance requires flat retained counts across equal settled batches and restart. Allocator high-water behavior alone neither proves nor disproves retained growth. Results belong in `.artifacts/accept/host-memory/`.
16. **Package boundaries enforce route capabilities.** Bridge invocation and journal launch internals live in an internal package. Routes import only typed read, submit, observe and stop constructors. Registration is generated from those constructors. Import-boundary lint checks resolved imports, re-exports and dynamic imports. `PreparedRead` has a private constructor inside admission. Converted handlers cannot import raw launchers, Promise service adapters or per-call runtime provisioning. The merge-base island guard and the post-phase-5 zero threshold enforce rule 2. These structural checks do not prove native cancellation or memory retention.

## Consequences

- Cancellation becomes trustworthy per lifetime (rule 10): a browser disconnect interrupts a request-owned read and retires a queued op that has not dispatched; a durable command continues under the journal; a dispatched op gets a cancellation outcome from Revit, not from the transport. Host stop closes one scope that kills every child and flushes the journal. This is the ground that undo of Pea writes, cross-thread and cross-tab permissions, and a different Pea permission model need before they can be tried. The phase 5 acceptance protocol is the proof; until it runs, the claim is UNPROVEN.
- `docs/features/host/EFFECT-V4-PATTERNS.md` sections that contradict this ADR carry a "superseded by ADR 0029" note; the doc keeps the v3 to v4 gotcha table.
- The `effect-edge` lint and the shrink-only per-file island baseline are the ratchet together. The lint alone says only "each one has a comment"; the baseline says "fewer than before".
- Island census at 36f76766: 74 product islands and 70 test islands, beside 6 declared edges. Product clusters: A `bridge.list` session lookup 21, B `bridge.invoke` 20, D provide-per-call 10, E log 7, C request body 5. Root cause: Effect for the bridge client only, so every Promise caller paid a `runPromise`. Expected trajectory of product islands: 74, then 71 after 3a (39f9dc7d), about 55 after 3b, zero after phase 5. End state of product edges: `process-main` and `cli-main` only. The test-runner edge remains only while rule 13 requires it.
- Scoped ownership alone does not establish flat memory. Rule 15 makes the perf thread's equal-batch and restart falsifier an acceptance requirement. UNPROVEN until that run shows flat retained counts.
- `invokeBridge` (`bridge.ts:98`) and every Promise adapter over a service are deleted in phase 5, not adapted.
- Pin: effect 4.0.2 (landed c510da4b). `effect/http`, `effect/process` and `effect/reactivity` are `@stability unstable`; the pin is exact and a bump is a wave of its own.
- Rejected: shape 2 ("services, handlers stay Promise"), because each service still needs a `runPromise` adapter per caller and the 60 sites move without going; shape 4 ("everything Effect now, including the zod kernel and a SQL-backed Work store"), because zod is the catalog's JSON Schema source until the schema wave re-bases the Pea projection.
