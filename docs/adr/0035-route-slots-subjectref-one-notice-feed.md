# 0035: Five route slots, one SubjectRef, one notice feed

Date: 2026-11-10. Status: accepted. Source: kaitpw's rulings in the kernel crusade thread after two rounds with four adjacent threads (Space, findings, UI triage, kernel audit) and two code censuses. Evidence: `.artifacts/runs/kernel-crusade-20261110/DIRECTION-r1..r3.md` and each thread's last two replies (Space 2727, Findings 91, Triage 228, Audit 1015). Amends [ADR 0026](0026-one-route-shell.md), [ADR 0027](0027-one-route-one-subject-one-consent.md) rule 15 and [ADR 0030](0030-pea-first-goal-core-plan-statecell.md) rules 9 and 10. [ADR 0034](0034-timeline-per-work-places-on-host.md) stands. Frontier: [routes MAP](../features/routes/MAP.md).

## Context

Four threads hit one wall from four sides. The kernel composes routes, but the things that recur live below the route: the Picture, findings, selection, StateCell, the Timeline, consent and status. No slot holds any of them, so each route re-authors them, and `fans/route.ts` imports web `ducts/` nine times to avoid authoring them twice. The audit measured a route at about 250 handwritten lines over seven files plus three generators, with 407 `unknown` and 247 casts in 86 shell files because `admitUnknown` discards the one strong type at the seam. Consent is drawn in five branches from one host state. "What needs a person" is derived twice, once on the host (`notices.ts`) for push and once in the browser (`navigation/ledger.tsx`) for pull. The legacy mount kernel is twenty files and about 3,950 lines that no slot route uses.

Three shapes were fought: S1, a closed set of deep kernel modules as typed slots; S2, an open capability protocol; S3, deepen in place. S2 lost four to zero: it fails the hydronic figure (a parameter-bound owner in 4 to 9 lines exists only because the kind is closed) and turns Pod authors into module authors. S3 is kept as the method, one slot per landing, each deleting what it replaces.

## Decision

1. **Five slots.** A route declaration has `subject`, `sheet`, `picture`, `goal` and `layout`, plus one Page knob `query` for route-owned fields no slot holds, and one chrome knob `title(ctx)`. Findings, pointers, the Timeline and consent are implicit kernel modules with nothing to declare. Only the kernel adds a slot, a binding kind, a key kind or a mark kind. kaitpw: "your set is beautifully minimal."
2. **SubjectRef** is the one identity for a subject everywhere: `{ source?, keyKind, key, placement?, sub? }`. `keyKind` is `UniqueId | system-name | name | workspace | region | group`; `key` is a UniqueId, a canonical JSON tuple for name keys, or a stable id for a region or group whose geometry and membership live in the Value; `placement` is an ordered link path and is orthogonal to `sub`; `sub` is `{ port } | { field }` and never a free string. A family type is part of the name tuple. A document mark is observation basis and never identity. One branded codec string decodes at every door. A Picture scope is a SubjectRef set, a box or a prism with a frame; it is a scope, not an identity.
3. **Sheet bindings** are three closed kinds: `parameter` (a Revit parameter, UniqueId key, no sub, no placement), `store` (the model store, any key) and `local` (Work only, feeds the Goal). The firm file is a resolution layer (ADR 0026), and a Pod member is a home of Work (ADR 0030); neither is a kind.
4. **Types are inferred** from the declaration and never generated. One `codegen:routes` run generates only registries: the route registry, the address table, the C# launch list and the route tree. Builtins infer at compile time; a Pod decodes the same declaration schema at the boundary, and `admitUnknown` becomes that decode. The per-route TanStack file, the per-route contract stub and the hand address map are deleted.
5. **Two chrome layers.** The topbar, then pane heads, nothing else. kaitpw: "im actually gonna ban 3 layers. pea's thread name should move into the pane header." Chrome derives from filled slots; the Places tab strip is the dock pane's head. Layout is data; `draw` returns a branded `Body` (`scrollBody` or `fillBody`); `Pane` and `GraphLayoutView` are not exported to route modules, and an import guard holds the line.
6. **Consent is drawn in two places:** the write button that asked, and the topbar sweep. The composer arming strip and both Timeline-head branches die. The tray card is the sweep in the tray shell.
7. **One notice feed.** The host owns one `notices` Reading with groups waits, working, interrupted, failed, unread. The browser join in `navigation/ledger.tsx` and the second projection in `notices.ts` are replaced by it. Push (the card, the OS notification) and pull (home Activity, tray Activity, the Mod+Shift+K empty state) read the same feed. The tray's job is the notice feed, consent and compact chat; settings and the launcher leave it.
8. **The goal slot draws the unresolved list** on every route the same way. The ducts inbox is that list, not a notice surface.
9. **Findings** is one Work per document under owner key `findings` on the existing bindings, keyed by SubjectRef, with kinds that declare their verdicts and a `place` in the route's attention codec. Pointers keep their noun and contract with `target: SubjectRef | Place` and no journal; a keep verb turns one into a finding.
10. **The legacy mount kernel is deleted now.** The routes on it (chat, pods, settings, family, rooms, index, ops, bind) go dark and return one by one on slots; the kernel-level ones are the UX exercise. duct-loss dies as a route and may return as a Pod. design-system leaves the kernel as a plain page, and the Space playground is a Picture specimen on it. kaitpw: "duct loss is just a calculator and design system is a swatch with no connections."
11. **The product storage root** moves to a shared drive mount as its own landing, with the model-copy exclusion kept.
12. **Order:** legacy delete, storage root, journal services, run islands, SubjectRef, chrome, sheet, picture, findings. Each landing ships its red falsifier and deletes what it replaces.

## Consequences

- ADR 0026 "the manifest is the graph" becomes "the declaration is five slots"; its Keys, layout grammar and state homes stand. ADR 0027 rule 15 "migrate in order" becomes rule 10 here. ADR 0030's counsel OPINION "Subject stays a route field, not a noun" is reversed: SubjectRef is a kernel noun. ADR 0030 rule 10 Pointers stand unchanged.
- Rejected: S2; folding Pointer into Findings (it rebuilds the rejected thread store and puts every highlight in the journal); a UniqueId-only key; `{ view, level, polygon }` as an identity; chrome at the radical pole with no route title; a fourth binding kind for the firm file.
- Owed, in the routes ledger: the Mod+K pane navigator listing; a person-resolver closer bridging into the notice feed; the ADR 0030 rule 9 Work undo per document, which findings needs.
