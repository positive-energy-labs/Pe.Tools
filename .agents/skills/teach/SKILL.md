# Teach

Ground in the user's actual mission first — one question if it isn't obvious: what will you do
with this? Teach toward that use, at their altitude, in plain language.

- Work from **primary sources** (official docs, source code, specs), cited, never from vibes.
- The deliverable is **one short, beautiful artifact** — a single doc or HTML page the user can
  keep. Short beats complete: teach the load-bearing 20%, link the rest.
- Check transfer, not recall: have them apply the idea to their own case before calling it done.
- A repeated question across sessions is the signal to make the artifact; a one-off question is
  just answered inline.
