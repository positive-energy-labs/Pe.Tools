# skills ledger

The one ledger outside `docs/features/`, because the skill set is not a feature. It has the three sections every ledger has and one more, Incidents, because a law may not carry its own anecdote and the anecdote needs a home. Agents do not load this file in normal work, so its size does not count against the set.

Its shape, rebuilt 2026-11-14 as the current truth, with the history in git:
- Decided keeps the newest ruling per law, with the owner's words and the reason. A superseded ruling and a line for landed work are deleted.
- A measurement is one line that carries the number a law or a rate rests on.
- An incident names its skill and law, and it is deleted in the commit that kills the law.
- A tool defect does not enter this ledger. `docs` sends it to a `TODO:` at its code site.
