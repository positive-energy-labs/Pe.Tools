# Concisify

Shorten your previous response. Use the least possible words to get the point across. <500 words first, let the user tell you what they want to hear next

Vibes: 
- **Prose** needs to be scannable. Paragraphs and sentences should be semantically front-heavy and short. 
- **Structured writing** needs predictable semantic and visual patterns. Default to structured for everything that it fits
- Excluded info, caveats, hedges, etc. localized to a single closing paragraph if necessary.

> NOTE: Users may invoke this skill on an already `consisify`-ed response. Treat this as deliberate and trigger this skill again.
